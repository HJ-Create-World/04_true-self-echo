# 陪伴感专项 · 沟通能力四个方向（细化设计）

> **什么时候读这份文档**：排期陪伴感迭代时。四个方向都已调研确认可行（2026-09/10），
> 本文只回答「具体做什么、做完什么效果、花多少成本」。
>
> **状态**：切片 1/2/3 已于 2026-10-08 实施（见 D015）；切片 4 已进提取 prompt，新投料生效。

> **总目标（HJ 2026-10-08 原话）**：虚拟人格保有角色特质与原本记忆的同时，具备人类发展的
> 特性 —— 感性、沟通、思考，像人一样陪伴，有人的温度，拒绝人机感 ——
> 二次元角色打破次元壁来到现实的感觉。

四个方向共享同一条工程路线：**能搭既有管道顺风车的绝不新增调用**。
记忆抽取（每轮一次 LLM 调用）已经是顺带产出「记忆卡 + 关系评估」的模式，
四个方向里有三个都挂在这趟车上，成本为零。

---

## 一、情绪动态（她此刻的心情）

### 问题
`MoodSwitcher` 只改界面柔光色，**prompt 里她没有任何情绪状态** ——
上一轮还在笑，这一轮用户说「我最近好累」，她的语气不会变。

### 做法
- `evolving` 层新增 `mood: { label, intensity(1-3), since, reason }`
- **评估搭记忆抽取的顺风车**：每轮抽取时 LLM 顺带产出情绪评估
  （已有 relation 同款模式，**零新增调用**）
- **惯性防抖**：intensity 1（微弱）不切换当前情绪；2–3 且与当前不同才切换 ——
  防止每轮情绪乱跳（情绪震荡是人机感的最大来源之一）
- **注入**：记忆区头部（关系行旁边）加「你现在的心情：…（因为…）」
- **UI**：档案页显示当前情绪；EvolutionCurve 已有的快照机制自动留下情绪轨迹

### 最终效果（示例）
```
用户：最近项目上出了点事，有点烦
她：〔心想〕他很少说「烦」这个字……
    嗯，不急着聊它。想说什么的时候我都在♪
    先吃点好的，晚上早点睡 —— 不许熬夜。
（她的心情变为「惦记」，接下来 2-3 轮主动语气变轻，
  甚至隔天主动开场时先问「昨天那件事，现在怎么样了」—— 与方向二联动）
```

### 成本与风险
- 成本：**0**（顺风车）；风险：情绪切换误判 → 靠惯性阈值 + 回滚机制兜底（快照本来就在）

## 二、Open loops（未闭环话题 —— 主动回访的素材）

### 问题
她问过但没被回答的问题、TA 提过要跟进的事、说好下次聊的话题 —— 全部沉没。
所以主动消息只能是泛泛的「在干嘛」，这是「人机感」的第二大来源：
**真人朋友记得你们没聊完的话**。

### 做法
- 记忆抽取顺带产出第三类产物 `loops`（复用 MemoryCard，kind 加 `'loop'`）：
  「问过没答的问题」「约定」「TA 说要跟进的事」，带 `open/closed` 状态
- **主动消息生成时优先消费 loops**：L1/L2 的隐藏指令从「主动说点什么」
  升级为「如果有没聊完的事，从它自然接起；没有才自由发挥」
- 用户回复了相关内容 → 自动闭环（抽取时判断）；也可在档案页手动关闭

### 最终效果（示例）
```
（三天前用户提过「下周有个面试」）
她（主动）：诶，是不是这周有个面试来着？
           我这两天偶尔会想起来 —— 紧张吗？
```

### 成本与风险
- 成本：**0**；风险：翻旧账式回访惹人烦 → loops 注入时带「提过几次」计数，同一 loop 最多主动提起 1 次，被回避即关闭

## 三、幽默与亲昵方式档案化（投料侧增强）

### 问题
玩笑全靠模型自由发挥 —— AI 通用幽默（谐音梗+俏皮话）会稀释角色特质。
素材里角色的逗人方式（自嘲 / 装凶 / 夸张比喻 / 撒娇节奏）没有被系统性提取。

### 做法
- **不新增数据结构**：`expressionDNA` 本来就是「小标题 + 行」的松散块，
  提取 prompt 加一个引导块「**幽默与亲昵**」—— 素材里的玩笑模式、
  逗人开心的具体招式、亲昵的分寸单独成块
- 渲染零改动（它就是说话风格的一部分）
- 诚实原则不变：素材里没有就留空，不编幽默感

### 最终效果（示例）
```
投料素材是某角色：惯用「本小姐才不会…」式傲娇 + 假装嫌弃实际关心
→ 提取后她的玩笑长这样：
   「哼，看在你诚实的份上，本小姐就勉强夸你一句好了」
而不是 AI 通用幽默：
   「哈哈哈你真有趣，像个小南瓜」
```

### 成本与风险
- 成本：**0**（提取 prompt 一次改动，新投料的档案生效）
- 边界：已有档案不回填（重新投料才有）；没有幽默素材的角色不硬造

## 四、用户沟通偏好适配（怎么跟这个 TA 聊）

### 问题
`userModel` 记了「TA 是谁」（事实），没记「TA 喜欢怎么被聊」——
对爱玩梗的人和对话少的人用同一套节奏。

### 做法
- 记忆抽取顺带评估用户的沟通偏好 → `userModel` 新增 `pref:*` 条目：
  爱接梗 / 吃鼓励 / 话少 / 夜猫子 / 不爱被追问 / 喜欢长聊 …（标签池有限个，防发散）
- **注入**：记忆区头部加一行「和 TA 打交道的分寸：…（从相处中观察到的）」
- **措辞用「倾向」不用「必须」** —— 标签是观察不是判决，防止把用户钉死在标签里
- 用户可在记忆面板**删除任何一条偏好**（她「自以为懂你」时你要能纠正）

### 最终效果（示例）
```
观察到「TA 话少，回复常是一两个字」+「深夜活跃」
→ 她的回复变短、提问变轻、深夜话题偏向安静陪聊；
   连续几轮用户回复变长 → 她自然放开，不需要任何手动开关
```

### 成本与风险
- 成本：**0**；风险：误判偏好 → 标签可删 + 抽取置信度低的直接不写

## 实施顺序建议（每项独立可验收，拆 4 个切片）

| # | 方向 | 依赖 | 工作量 | 验收要点 |
|---|---|---|---|---|
| 1 | 情绪动态 | 无 | ~1 晚 | 心情切换有惯性；注入后语气可感知变化；曲线有轨迹 |
| 2 | Open loops | 无 | ~1 晚 | 主动消息优先接旧话题；同一 loop 只提 1 次；可手动关闭 |
| 3 | 用户偏好 | 无 | ~1 晚 | 标签池有限；注入措辞是倾向；面板可删 |
| 4 | 幽默提取 | 下次投料生效 | ~0.5 晚 | 有素材的角色玩笑有出处；无素材的诚实留空 |

> 1→2 有联动收益（情绪 + loops = 「隔天先问那件事」的完整体验），建议先做这两个。
