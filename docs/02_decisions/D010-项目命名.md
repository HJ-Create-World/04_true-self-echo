# D010 · 项目命名

> **什么时候读这份文档**：想改项目名时；有人问"为什么叫这个"时；在别处发现「真我」这
> 个词被占用、想知道我们是否知情时。
>
> **它不是**：品牌规范（那是 `06_ops/` 该管的事，目前尚未建立）。
>
> **它能回答**：为什么叫「真我回响」？考虑过哪些别的？有什么已知风险？

---

## 一、决策

**2026-09-18，HJ 决定项目中文名定为「真我回响」，英文名 `true-self-echo`。**

| 项 | 值 |
|---|---|
| 中文名 | **真我回响** |
| 英文名 | `true-self-echo` |
| 曾用名 | `persona-forge` / 人格工坊（2026-09-15 立项时命名） |
| 决策人 | HJ |
| 生效范围 | GitHub 仓库名、文档抬头、UI 品牌位 |
| 决策方式 | HJ 在知情前提下拍板（见 §五） |

---

## 二、背景：为什么原来的名字不够用

原命名 `persona-forge` / 人格工坊是立项时的**功能性描述** —— "打造人格的工坊"。
它的问题不是难听，而是**没有辨识度**：

- `persona-forge` 是典型的 AI 项目命名套路（`*-forge` / `*-lab` / `*-kit`）
- 「人格工坊」直译自英文，读起来像工具站的名字
- 二者都无法承载"这个项目想表达什么"

HJ 于 2026-09-17 提出更名，原话要求：**"高级一点，像月之暗面的那种感觉"**。

---

## 三、命名构造方法论（本次调研的核心产出）

调研三个中文 AI 品牌，发现它们**共用同一个三层公式**：

| 层 | 作用 | 月之暗面 | 无问芯穹 | 智谱 |
|---|---|---|---|---|
| **表层意象** | 给出看得见的画面 | 月球背面 | 芯片 + 苍穹 | 智慧的光谱 |
| **里层隐喻** | 给出一句话主张 | 真正重要的东西在视线尽头 | 不问智慧的边界 | 走到智能的终极境地 |
| **私人锚点** | 给出真话（不是包装） | Pink Floyd 专辑《The Dark Side of the Moon》 | 清华校歌「立德立言，无问西东」 | —（自造词，无锚点） |

> 🔴 **关键判断：高级感来自「私人锚点」，不是把词堆得玄乎。**
>
> 「月之暗面」若改叫「深智」「元芯」，就只剩包装 —— 它高级是因为背后**真有一张专辑**，
> 而且创始团队恰好是摇滚爱好者（创始人杨植麟大学时是乐队鼓手）。
> 这种「私人趣味 × 宏大隐喻」的错位才是不可复制的东西。

**这条方法论对后续命名同样有效**，故记录在此。

## 四、候选与淘汰

### 4.1 已淘汰

| 名字 | 淘汰原因 |
|---|---|
| 拾遗阁 / 旧砚台 / 花海笔录 | 文房四宝与"笔录"路子，偏古风，与 AI 项目气质有距离 |
| 余烬 | 暗示"已经烧完"，与"人格还在成长"的产品逻辑矛盾 |
| 铸语 | 意象太硬，金属感压过了陪伴感 |
| 醅（pēi） | 隐喻最好（素材自己熟成）但单字 + 生僻读音，做仓库名和 UI 都不便 |
| 陶漉 | 与「拾音」意象重叠（都在"滤/拾"），二选一 |
| 铭纹 / 篆渊 / 拓印 | 三者同属"刻写"分支，方向重复；HJ 判断整体调性不对 |
| 乐土拾遗 | 里层直接绑定崩坏3 的「往世乐土」，对外品牌不可用 |

### 4.2 最终选择

**「真我回响」**，其三层结构：

| 层 | 内容 |
|---|---|
| **表层意象** | 真实的我，在声音里回响 |
| **里层隐喻** | 喂进去的是素材，出来的是**那个人的真我**；「回响」暗示它是回声而非本人 |
| **私人锚点** | HJ 是崩坏3 玩家，爱莉希雅的刻印即「真我」，其装甲名为「真我·人之律者」 |

> 📌 「回响」二字另有一层贴合：本项目的产品定位是**透明陪伴者** ——
> 你能看见它「变了什么」。**回响是能被听见的**，这与"可观测"的设计取向一致。
>
> 同时「回响」为将来的**语音模块（TTS）**预留了语义空间。

## 五、🔴 风险记录（HJ 知情后决定采用）

**「真我」二字被双重占用，这是已知事实，不是疏漏。**

| # | 占用方 | 场景 | 后果 |
|---|---|---|---|
| 1 | **realme**（OPPO 旗下手机品牌） | 2022-05-26 启用中文品牌 logo「真我realme」，全球 3 亿用户 | 搜索"真我"结果全为手机；若将来商业化可能撞名 |
| 2 | **崩坏3 / 爱莉希雅** | 逐火十三英桀的刻印名「真我」（位次 Ⅱ） | 崩3 玩家可能误判为同人项目 |

**处理过程**：

1. 2026-09-18 完成事实核查（realme 官网 / 百度百科 / 新京报报道）
2. **已向 HJ 明确说明**，并给出替代方案「本真回响」（同义、无占用）
3. HJ 明确选择**沿用「真我回响」**

**结论：本项目为非商业的个人项目，采用此名的风险可接受。**
若将来商业化，需重新评估（届时「真我」大概率不可用）。

> ⚠️ 本条记录的目的是**留痕**，不是推翻决策。将来任何人问起"知不知情"，
> 答案是：知情，且已评估，且接受。

## 六、后果

### 正面

- 项目获得可承载的表达，不再是功能性描述
- 「回响」为语音模块预留语义空间，将来做 TTS 不用改名
- 三层构造方法论沉淀下来，后续同类命名可直接复用

### 代价

- **「真我」双重占用**（§五）—— 非商业使用可接受
- 英文名 `true-self-echo` 偏直译，不如中文名有味道
- 曾用名 `persona-forge` 会在历史提交记录、归档文档中长期残留
