## 一、切片 1 · 情绪动态（已实施）

- `EvolvingLayer.mood?: { label, intensity(1-3), since, reason }`
- **评估搭记忆抽取顺风车**：抽取 prompt 增加第三节「她此刻的心情」，
  显式划清边界——性格（frozen）不许抽，**临时情绪**要评估；没有起伏输出 null
- **惯性**：intensity 1 的淡情绪不切换当前状态（现在没有情绪时可作为起点）；
  同 label 不重置 since —— 情绪要能「持续一段时间」才有人的感觉
- **注入**：记忆区头部心情行，措辞「自然融进语气——不用宣布它，也别假装没有」
- **UI**：档案页「她现在」卡显示当前心情与缘由

## 二、切片 2 · Open loops（已实施）

- `EvolvingLayer.loops?: LoopItem[]`（question 问过没答 / promise 约定 / followup 有后续）
- **产出与闭环都在同一次抽取调用里**：模型收到现有 open loops 清单，
  判断本轮对话让哪些了结（closedLoopIds，拿不准不关）；新 loop 与旧内容去重，上限 20
- **主动消息优先消费**：有 fresh loops（raisedCount 0）时，L1/L2 指令追加
  「从其中一件自然接起」——**「你上次说的面试怎么样了」远胜于泛泛的「在干嘛」**
- **防翻旧账**：同一 loop 主动提起一次即 +1（不再进主动指令、不再进常规注入）；
  用户可在档案页手动关闭（「不用提了」）
- **注入**：记忆区「还没聊完的话」块（只注 fresh 的前 3 条）

## 三、切片 3 · 世界动态 · 共享语境（已实施，手动层）

### 🔁 对 D014「不做搜索」结论的修正（HJ 2026-10-08）

原评估把「联网」理解成了**「她帮你查资料」**（助手化），结论不做。
HJ 的反驳成立：用户分享的日常和现实息息相关（新品 / 热点 / 社会事件），
**她听不懂你在聊什么，才是真正的人机感**。这不是搜索需求，是**共同语境**需求——
真人朋友对世界有共同感知。

### 修正后的三层路线

| 层 | 做法 | 状态 |
|---|---|---|
| **L1 手动世界动态**（本轮） | 设置页「最近的世界」textarea，用户顺手贴几条（本来就在刷手机，成本极低）；注入措辞是**「你刷到过、听说过」**——真人式印象，不是检索结果；「没细看就照实说」「不确定就承认」 | ✅ |
| L2 RSS 自动层 | 用户配几个信息源，每天拉标题注入 | 远期（RSS 源质量参差，价值待验证） |
| L3 搜索层 | 可选搜索 API key（Tavily 免费层 1000 次/月），触发式调用 | 远期（有 key 才启用，同天气的「可选配置」模式） |

### 合规边界
她聊热点是**接你的话**，不是发起社评；注入措辞限定「闲聊热点那样、
不确定细节就承认」——不给虚拟角色对社会事件下判断的任务。
