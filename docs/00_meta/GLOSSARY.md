# GLOSSARY · 术语表

> **什么时候读这份文档**：看到不认识的术语、或不确定某个词在本项目里的确切含义时。
>
> **它不是**：通用 AI 词典。只收录**本项目特有**或**在本项目有特定含义**的词。
>
> **它能回答**：XX 是什么意思？它和 YY 有什么区别？

---

## 一、核心概念

| 术语 | 定义 | 易混淆点 |
|---|---|---|
| **人格档案**（Persona Profile） | 从素材提取出的结构化人物描述，用来驱动 LLM 扮演。**本项目唯一的核心抽象** | 不等于"角色卡"（那是 SillyTavern 的格式）；不等于"微调后的模型" |
| **冻结层**（Frozen） | 人格档案中**AI 不可修改**的部分：核心性格、价值观、说话基调 | 管「怎么说」，不管「知道什么」 |
| **演化层**（Evolving） | 人格档案中**自动累积但可见可回滚**的部分：对用户的认知、关系状态、共同记忆 | 管「知道什么」 |
| **表现型特征** | 要**演出来**的特征，Prompt 里用**正向描述** | 例：句子短、用破折号 |
| **约束型特征** | 要**禁止说出来**的特征，Prompt 里用**反向禁令** | 例：禁止直接陈述情感状态。**AI 味的根因是模型倾向于把内心戏讲出来** |
| **人格漂移**（Persona Drift） | 人格随时间偏离初始设定的现象 | 学术上有量化公式：`Drift = (1/T)·Σ‖v_t − v_0‖₂` |
| **投料** | 用户上传素材（聊天记录/台词/小说）的动作 | |

## 二、实验相关

| 术语 | 定义 |
|---|---|
| **材料层级** | 素材提供的信息层数。**单层** = 纯对话/纯台词；**双层** = 含语言之外的信息（动作/表情/场景/他人视角） |
| **情绪类型覆盖率** | 素材覆盖的场景情绪种类数。**比字数更重要** —— 至少需 3 场景 + 1 个非温柔情绪场景 |
| **表现型 vs 约束型** | 见上表 |
| **考题带答案** | 实验设计陷阱：素材里直接明写了要考的核心特征，导致结论偏乐观 |
| **必然失败项** | 对照实验的探针：故意设计一个**无信息源**的特征，若模型声称抓到，说明它在编 |
| **自我批卷偏差** | 提取和评测由同一模型完成时的系统性偏乐观风险 |
| **层级清洗** | 把混在素材里的"分析结论"剔出去的动作（区别于"层级检测"） |

| **解码退化**（repetition loop） | 模型陷入完全相同的重复输出，直到撞上 `max_tokens`。实测样例：GLM-4.6V 输出 3533 字，后 3000 字是同一段话重复约 60 次 | ≠「回复长」。判据是**重复**，不是长度。检测算法见 [`execution-control.md` §4.2](../03_specs/execution-control.md) |
| **思维链**（thinking / reasoning） | 模型在给出正式回答前先做内部推理。**会引入「模型自己推理如何遵守约束」这一混杂变量** | 关它是为了**归因**，不只是省钱。关掉后省 7.3 倍 token（E5 附录 C） |
| **提示缓存命中**（prompt cache hit） | 服务端复用上一次相同 prompt 前缀的计算结果。**命中价 = 未命中的 1/50** | ⚠️ 把每轮变的 reminder 放进 system 会**毁掉缓存**（贵 50 倍）。见 `execution-control.md` §4.1 |
| **基座模型**（base model） | 承担生成能力的底层模型。本项目主基座 = **DeepSeek V4.1-Flash** | ≠「微调后的模型」。`D005` 已决定不做微调，所以基座能力就是效果上限 |
| **消息组装**（message assembly） | 路线 1 的干预对象：system 段 + few-shot + 历史 + 本轮前缀 的**拼接方式与位置** | 与「改 prompt 内容」不同，它改的是**位置和重复** |
| **约束三明治** | 把约束文本**同时放在 system 的开头和末尾**。贡献最大的干预手段（+6） | 不是「写得更强调」，是**利用首尾位置效应** |
| **每轮重注入** | 把约束尾句作为**最后一条 user 消息的前缀**每轮重发 | ⚠️ 必须是**前缀**，不是额外插一条消息。见 `execution-control.md` 两条顺序约束 |
| **成对示例** | 给「❌ 错误示范 → ✅ 正确示范」对照。**实测有害（−6）** | 模型会把示例的「具体化倾向」泛化到别处，不只是照抄 |
| **provider** | `.env` 里的模型后端名（`glm` / `deepseek` / `ollama`）。**换模型 = 改三行** | 三后端共用同一套调用代码（OpenAI 兼容协议） |
| **峰谷定价** | DeepSeek 的按时段差价：北京时间 周一至五 09:00–12:00、14:00–18:00 是谷时的 **2 倍** | 批量实验排晚间或周末 |

### 实验编号

| 编号 | 含义 |
|---|---|
| `P0-{n}` | 第一轮 Phase 0（历史遗留命名） |
| `E{n}` | 后续实验，E1 起递增 |
| **E5 子实验** | **不单独占编号**（如思维链 × 退化测试）。原因：E6 已预留给「独立模型复核」 |
