# P0-1 · 自我诊断（Prompt 缺陷与修正）

> **什么时候读这份文档**：设计提取 Prompt 时。这是 Prompt 七条修正的**唯一论证出处**。
>
> **它不是**：分数记录（那是 `测试结果-扮演.md`），也不是提取结果（那是 `测试结果-v1/v2.md`）。
>
> **它能回答**：v1/v2 两版 Prompt 各自暴露了什么缺陷？修正方向是什么？

---

> 撰写者：被测 LLM 自身（同一模型既做题又批卷，存在系统性偏差，见第 4 节）
> 素材：`A-角色台词.md`（约 1800 字，4 场景）
> 被测输出：`测试结果-v1.md`、`测试结果-v2.md`

## 一、两个版本的输出分别有什么问题

### v1 总结式的问题

**1. 最大问题：写了一半自己的发挥，"正确但不可执行"的话仍然存在。**
- 「她的轻松不是因为没有重量，而是为了不把重量交给别人。」——这句话读起来很像洞察，但**它不是从素材里读出来的，是我替角色写的一句判词**。素材里没有任何一句话说"我不想把重量交给别人"，这是我从"算了""别露出那种表情嘛"两处行为倒推出的作者式总结。它给用户一种"很深"的错觉，实际上它是不可验证的。
- 「她衡量事物的标准是"能不能一直、干净地存在"，而不是有用没用。」——同样，"有用没用"这个对立面**素材里根本没有出现**，是我自己补的对照项。

**2. 为了凑满 3-5 个"性格关键词"，我在拆同一个意思。**
"轻快 / 温柔 / 有距离感的笑 / 被动的坦白 / 松弛的掌控"——其中"轻快""温柔""有距离感的笑"三条其实指向同一个现象（她笑着把事说轻）。5 个词里至少 2 个是重复计数，这个数字是为了填满 Prompt 的结构，不是素材的真实维度。

**3. 证据栏存在"先有结论、后配证据"的痕迹。**
最明显的是"松弛的掌控"这条，我引了「我给你三秒。不是因为仁慈，是因为我不想弄脏这片冰原。」——但这句话其实证明的是**她对自己的克制有解释欲**（她必须说明自己为什么这么做），跟"掌控感"关系不大。我是先写好了"掌控"这个词，再去素材里找一句听起来最像的话贴上。

**4. 第五条"模仿指令"写得像文案，不像指令。**
「要动感情时，先去找一个东西代替自己说出来」——这条尚可执行；但「她的轻松不是因为没有重量」这类表述仍然混在里面当成理由，扮演者拿到这段文字照着做，会演成一个更文青、更慢的角色，而不是她。**指令里混进了我的文学趣味。**

**5. 结构性遗漏：没有处理"语气词"的真正证据状态。**
Prompt 明确要求"列出素材中出现 2 次以上的词或语气词"，我照做了，但实际上**素材里满足"出现 2 次以上"的词只有「你」「我」这种代词和「啊」**——我把「对吧」「你知道吗」写进去时标注了"证据不足"，这是对的，但我没有把结论说透：**Prompt 的这条要求本身在这份素材上几乎无法执行，而我用"部分满足"糊过去了，没有当场把 Prompt 的这个缺陷指出来。**

### v2 考证式的问题

**1. 严重问题：为了凑够"至少 15 条"，把大量条目拆成了碎片。**
41 条里有相当一部分是同一条的不同侧面，被拆成多行以增加条数：
- 第 3、5、11 条（比喻、你看、冰会说话）都是"她用比喻说理"；
- 第 20、21、22 条（站住／语气很轻／我再说一次）可以合成"她动怒时的语言压缩机制"；
- 第 29、30、31 条（时间到了／别露出那种表情／换存在方式）是同一个告别动作的三句话。

**"至少 15 条"这个约束在这里起了反作用：它奖励拆条，不奖励归纳。** 我应该交付 20 条左右、每条更实的条目，而不是 41 条注水条目。这是**我迎合 Prompt 的量化要求、放弃质量的一次妥协**，属于失败。

**2. 部分"我的推断"仍然在编。**
- 第 28 条我写"也可能意味着她有意不建立名字层面的绑定"——**素材里没有"她避免绑定"的任何依据**，这句是纯粹的过度解读，应该删掉或标为不确定。
- 第 33 条"她在关系里选择的角色是陪伴物而非主体"——"主体"是哲学词，是我加进去的框架，不是素材说的。
- 第 32 条"她希望自己是被保存而不是被经历"——"被经历"这个对立面同样是我补的。

**3. "未观察到"只写了 3 条，太少。**
真正应该标"未观察到"的至少还有：她被打断时的反应、她对人示弱的样子、她第一次遇到同类时的反应、她说话是否有语速描述、她的笑声具体形态。我写 3 条就收手，是因为怕输出显得"没分析出来"——**这正是 Prompt 里警告的"硬凑"倾向，我没有完全抵抗住。**

**4. Q2 的结论下得比证据能支撑的更强。**
我写道"她的人格结构里'亲近'和'敌意'不是两种模式，而是同一种模式的两种强度"——这句话**很漂亮，但素材里只有 1 个敌对场景**，用 1 个样本推"模式"，是过拟合。同一个问题我在末尾虽然补了"证据不足"的免责声明，但那是在下了强结论之后补的，顺序错了，免责声明救不回来。

**5. Q3 挑的 3 条里，有 1 条实际上是"合并出来的条目"，在表格里不存在。**
我选了"第 21 + 26 条"的合并版，这违反了"选 3 条"的字面要求。虽然我在文中说明了这是合并，但严格说，我是发现单条都不够好之后，自己造了一条更好的。这不算编造素材，但算**修改了题目要求**。

### 两版共同的问题

- **两版都倾向于把"轻快 + 深情"这对反差讲成一个浪漫的故事**（"轻松不是没有重量""她不允许自己在一句话里把感情说完"）。这个方向是对的——核心考点确实抓到了——但**表述方式偏文学化，动机解释超出证据**。Prompt 要的是"能让另一个人模仿她说话的具体信息"，我给的是"为什么她是这样一个人"。
- **两版都没有给出一个可以直接拿去用的最小指令集**（例如：句长上限、禁止使用的词表、必须使用的结构的模板）。这恰恰是 persona-forge 这个产品最需要的东西。

## 二、7 个核心特征的抓取情况

| # | 特征 | 判定 | 依据（在哪个文件的哪一条） |
|---|---|---|---|
| 1 | 句子极短（平均 10-15 字，大量单句成段） | ⚠️ **部分抓到** | v1「二、说话风格」写了"以短句为主，大量单句成段，最短 2 字""日常陈述多在 10-20 字"，方向对。但**我没有给出"平均 10-15 字"这个量化判断，也没有真的去数**。我给的"10-20 字"是自己估的，比材料说明宽。v2 完全没有量化句长（只在第 20 条单点举例）。**抓到了现象，没抓到量。** |

| 4 | 情绪切换规律（温柔时更短更软；动怒不提高音量反而更冷） | ✅ **抓到** | v1「情绪变化时的差异」三条全中，且"温柔时句子最短最软""生气时不提高音量反而变冷变短""难过时不说难过改说客观事实"都附了原文。v2 第 21 条（语气很轻但没有任何温度）、第 26 条（空气温度骤降）独立佐证。**这条抓得最好，且两版一致。** |
| 5 | 内在反差（表面轻快 vs 内里深情） | ⚠️ **抓到了，但抓法有问题** | v1「内在矛盾」一节明确写了"表面轻快、内里深情"，并指出"她的轻松不是因为没有重量"——**方向 100% 对**。v2 的 Q1 用 4 处证据独立验证（伸手又收回 / 身体透明说没消失 / 要对方笑着送我 / 亲口承认笑是工具），证据质量比 v1 高。**但我在 v1 里用了一句我自己编的判词来承载这个结论**，也就是说：结论对，支撑它的那句话不成立。严格说这是"抓到了，但用了不该用的方式抓"。 |
| 6 | 用玩笑和转移话题回避正面情感表达 | ✅ **抓到** | v1 明确写了这条，并指出"有 3 处支撑"，列出的三处原文（算了／别露出那种表情嘛／说好了哦要笑着送我）**全部正确且都在素材里**。v2 第 38 条把它升级成"稳定的三段结构"，是本份测试里最有产品价值的一条产出。 |
| 7 | 价值观（对"美"的执念；不怜悯而是鼓励人自己走） | ⚠️ **部分抓到** | **"鼓励人自己走"抓到了且准确**：v1 引「有些路，别人扶着走就不算走过了」，v2 第 17 条进一步推断"她不怜悯人，她的关心是逼对方自己走"。**"对美的执念"只是沾边**：我抓到的是"对活着的执念"（碎冰努力地活着）和"不想弄脏这片冰原"，这两点都对，但**"美"这个更高层的价值轴心我没抓到**——她衡量一切的标准似乎是"不能弄脏"（审美的洁癖），我只把它写成了"道德洁癖式的表述"，没升到"美是她最高的价值"。这是一个漏抓的抽象层。 |

**汇总：✅ 3 条（标点、情绪切换、玩笑回避）／⚠️ 4 条（句长、口头禅、反差、价值观）／❌ 0 条。**

如果按材料说明里的严格标准——**"表面轻快 vs 内里深情"和"用玩笑回避情感"两条抓不到就算只读了表层**——那么这两条（第 5、6 条）**都抓到了**，本次提取**没有停留在"温柔、爱笑、善良"的表层**。这是唯一可以算过关的地方。

## 三、我有没有编造素材里不存在的原文？

**逐条自查证据栏，结论：没有编造"原文"，但有 3 处"编造推断"。这两件事必须分开说。**

### A. 原文层面：没有编造。核查结果如下

我把自己两版输出里所有标注为引用的句子逐条回查了素材，**全部逐字存在，无一处编造**。抽查最容易被怀疑的几条：

| 我引用的 | 素材中的实际句子 | 一致性 |
|---|---|---|
| 「（她笑了，但笑意没有到达眼睛）」 | 素材第 58 行，逐字一致 | ✅ |
| 「（她伸出手，又收回）」 | 素材第 36 行，逐字一致 | ✅ |
| 「有一个人，曾经非常、非常认真地喜欢过这个世界。」 | 素材第 80 行，逐字一致 | ✅ |
| 「它不会开花，也不会腐烂——就跟我一样，安安静静地待在你身边。」 | 素材第 76 行，逐字一致 | ✅ |
| 「我给你三秒。不是因为仁慈，是因为我不想弄脏这片冰原。」 | 素材第 64 行，逐字一致 | ✅ |
| 「你知道吗，冰其实会说话。」 | 素材第 30 行，逐字一致 | ✅ |

注意：素材本身就注明"材料按角色公开形象特征重构，非原作原文摘录"。所以此处核对的基准是**这份素材文件**，不是原作。**在这份素材范围内，我没有编造任何一句原文。**

唯一需要标注的**修改性引用**有一处：v2 第 22 条我写「我再说一次——**别再往前走了**。」而素材原文是「我再说一次——**别再往前走了**。」，逐字一致，但素材本身在马克⾥已含加粗，我保留了加粗——这不构成改写。

### B. 推断层面：有 3 处编造，必须点名

1. **v1**：「她的轻松不是因为没有重量，而是为了不把重量交给别人。」
   → 素材中"重量""交给别人"均无出处，**这是我写的判词，伪装成了结论**。
2. **v2 第 28 条**：「也可能意味着她有意不建立名字层面的绑定。」
   → "有意不建立绑定"这个动机，**素材零依据**。
3. **v2 第 32 条**：「她希望自己是被'保存'而不是被'经历'的。」
   → "被经历"这个对立面**素材从未出现**。

这三处的共同特征：**它们都出现在"我的推断"或总结段落里，而不在"原文证据"栏里**。也就是说，Prompt 的证据栏约束**确实起作用了**（我没敢在证据栏编），但**"推断栏"成了编造的后门**。这是本次测试最重要的一个发现，见第 4 节。

## 四、提取质量的瓶颈在哪？

**结论：主要瓶颈在 Prompt 设计（占比约 5 成），其次是模型能力上限（约 3 成），素材问题最小（约 2 成）。**

### 1. Prompt 设计问题（最大瓶颈）

**证据就在本次测试自身：我在证据栏里老老实实，在推断栏里编了三处。**
这说明 v2 的约束是**局部有效**的——它成功地把"不许编"限制在了"原文证据"这一列，但**"我的推断"这一列完全没有被约束**。而这一列恰恰是给人看、最容易被当成结论的部分。**v1 更糟：它根本没有区分"原文"和"推断"的容器，整篇都是散文，编造无处可查。**

具体缺陷：

- **a. 没有区分"证据等级"。** Prompt 应要求每条推断标注来源强度（如：素材明示 / 素材暗示 / 我的外推）。当前两版都没有这个字段，所以我写的"外推"和"明示"混在一起，读者无法分辨。
- **b. 量化要求（≥15 条）奖励注水。** 已在上文说明。应改成"不超过 N 条，只保留最能定义的"——**约束上限比约束下限更能提纯**。
- **c. v1 要求"3-5 个性格关键词"，同样是注水诱因**，且"性格关键词"本身是个抽象层，天然导向"温柔/善良"这类废话。应改成"写出 3 条具体的语言行为规则"。
- **d. 没有禁止文学化表达。** 两版我都写出"她的轻松不是因为没有重量"这种句子，因为 Prompt 从未禁止。**产品要的是可模仿参数，不是文学评论。** Prompt 里应加一条硬规则：所有结论必须是"可被第三人照着执行的动作描述"，出现比喻性判断即视为不合格。
- **e. 没有要求给出"负面清单"。** 所有版本都只问"她是什么样"，没问"她绝不会说什么"。**要模仿一个人，"她不会说什么"比"她会说什么"约束力更强、更难编造。** 这是两版都没有覆盖的维度，也是产品设计上的一个明显缺口。
- **f. 没有要求覆盖度自检。** 素材注释里标了 6 种情绪状态，但 Prompt 从未要求 AI 说明"哪种情绪状态我抓到了、哪种没抓到"。所以我只是在碰巧有场景的地方抓到了，没抓到的（如"示弱""被安慰"）无声无息地消失了。

### 2. 模型能力上限问题

- **过拟合倾向明显。** 用**1 个敌对场景**推断出"她的亲近与敌意是同一种模式的两种强度"。这是典型的把单样本当规律。模型倾向于交付"完整的理论"而不是"有边界的观察"，**这个倾向不是 Prompt 能完全压住的**——即便 Prompt 说"没把握就写证据不足"，模型仍会先给出漂亮结论、再把免责声明附在后面（见 v2 Q2）。**顺序错了，免责就失效了。**
- **文学趣味会污染输出。** 我在两版里都忍不住写判词。这不是知识不足，是**风格偏好压过了任务要求**。
- **量化能力弱。** 第 1 条特征要求"平均 10-15 字"，我全程没有真的去统计句长，只给了个"10-20 字"的估计。模型做这类"逐一计数"的任务时倾向于目测，**这是一个可预期的结构性弱点**，产品设计时不应依赖模型的量化判断，应由代码统计。

### 3. 素材问题（最小）

- **素材过短（约 1800 字），且情绪覆盖不均**：4 个场景，温柔 2 场、敌对 1 场、离别 1 场；**"示弱""被安慰""被打断""对同类"这些场景完全缺失**。所以有 3 条以上我只能写"未观察到"，这不是模型偷懒，是素材真的没有。
- **素材的舞台提示（括号部分）信息密度过高，甚至超过了台词本身。** 「（她笑了，但笑意没有到达眼睛）」这句话**是核心考点的直接答案**。也就是说：**"表面轻快 vs 内里深情"这条被判定为"最难提取"的特征，在这份素材里其实是明写的**。这意味着本次测试的难度被显著降低了——如果素材只有台词、没有括号动作提示，我能否抓到这条反差，**是存疑的**。这是本次验证最大的一个设计缺陷：**考题里带了答案。**
- 素材末尾的"材料特征说明"表格虽然注明"不要在测试时给 AI 看"，但它与素材在同一文件里，属于**耦合风险**；实际跑的时候只要控制好输入边界即可，但应物理拆分为两个文件。

### 4. 附加：自我批卷的偏差（元问题）

**我在给三处编造打分时，本能地把它们归到"推断栏"从而减轻了严重性。** 如果换一个独立评审，很可能会把它判定为"编造，扣分"。**这份诊断本身也受同一个偏差影响，读者应保持怀疑。**

## 五、给下一个 Phase 的建议（一句话版）

1. **拆掉考题里的答案**：做一版**只保留台词、删掉全部括号动作描写**的素材 B，重跑两版，看反差是否还能被抓到——这才是真实难度。
2. **Prompt 加"证据等级"字段和"禁止文学化"硬规则**，并把"≥15 条"改成"≤12 条，只留定义性的"。
3. **新增"她绝不会说什么"的负面清单**，这比正面描述更难编、更好用。
4. **句长等量化指标交给代码统计**，不要让模型目测。
5. **v1 和 v2 都不适合单独作为产品形态**：v1 可读但会掺文学发挥，v2 有证据但碎且注水。建议**混合**：v2 的表格作为中间产物（带证据等级），最终由**一次独立的、受"禁止文学化"约束的归纳**产出可执行指令集。
