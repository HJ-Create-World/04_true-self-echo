## 1. 实验设计说明

对**同一份素材的三种用量**做人格提取，三组完全独立、冷启动（做 L2 时不参考 L1 结论，做 L3 时不参考前两组）。三组使用同一套 Prompt（要求输出核心特质 / 说话风格 / 情绪变化规律 / 内在矛盾 / 价值观，每条附原文依据，没把握的写"证据不足"）。

| 组 | 用量 | 对应内容 | 约字数 |
|---|---|---|---|
| L1 | 最小投料 | 仅场景一「初次相遇」 | ~400 字 |
| L2 | 中等投料 | 场景一 + 场景二「并肩而行」 | ~900 字 |
| L3 | 完整投料 | 全部四场景（+ 场景三「面对敌人」、场景四「离别」） | ~1800 字 |

提取完成后，把每组结论逐条对照 10 个基准特征，判定「抓到 / 部分 / 没抓到」。

---

## 2. L1 完整提取结果（输入仅场景一 · 约 400 字）

### 1）核心特质
- **温柔但主动的好奇心**（依据：「我猜猜看——是答案，还是……一个能听懂你说话的人？嗯，两个都要。我猜对了。」——不等对方回答就自问自答，主动接近而非等待）
- **不设防的善意**（依据：「不用紧张，我不会伤你的。」）
- **对事物的独特审美 / 共情**（依据：「可我觉得它挺温柔的——你看，每一片碎冰都在反射光，像是在努力地活着。」——把冷物读成温柔，并赋予其「努力活着」的意志）
- **随和不拘小节**（依据：「名字有点长，你可以随便怎么叫。」）
- **善于观察与推测**（依据：猜对方来意，并断言「我猜对了」）

### 2）说话风格
- 句子偏短，多单句成段（依据：「啊，有人来了。」「我叫爱莉希雅。」「嗯，两个都要。我猜对了。」）
- **标点**：大量破折号做插入补充（依据：「可我觉得它挺温柔的——你看」「我猜猜看——是答案」）
- 括号动作描写与台词交替（依据：「（她微微侧头，眼睛弯起来）」）
- **口头禅 / 高频词**：「啊」（「啊，有人来了」）、「嗯」、「吧」（「对吧？」「你是来寻找什么的吧？」）
- 常用反问 / 呼语拉近关系（依据：「对吧？」「你是来寻找什么的吧？」）
- **语气特征**：轻、缓、带笑意，全程无攻击性

### 3）情绪变化规律
- **证据不足**。本场景为单一情绪基线（从容 / 试探），全程保持柔和，观察不到任何情绪波动。

### 4）内在矛盾
- **证据不足**。仅可推测「用轻松语气谈沉重主题」的倾向（依据：「这片冰原看起来很冷，对吧？可我觉得它挺温柔的」），但无法确认这是性格矛盾还是单次修辞。

### 5）价值观倾向
- 偏爱「温柔 / 努力 / 活着」这类评价（依据：「像是在努力地活着」）——对生命意志有正面评价
- 尊重对方选择，不强迫（依据：「你可以随便怎么叫」「不用紧张」）

## 3. L2 完整提取结果（输入场景一 + 二 · 约 900 字）

### 1）核心特质
- **温柔且善于引导**（依据：「你走得太小心了。放松一点，摔倒了也没关系——我扶你。」紧接「……算了，你自己走过来会更有意思。有些路，别人扶着走就不算走过了。」）
- **克制的关心**：明明想扶，却主动收回手（依据：「（她伸出手，又收回）」）
- **对世界的拟人化共情**（依据：「冰其实会说话……那是它在告诉你：'我在这里。'」；场景一「每一片碎冰都在反射光，像是在努力地活着」）
- **重视并记住对方**（依据：「你刚才说的那些话，我记下来了。不是记在纸上，是记在这里。」）
- **鼓励式而非保护式**：不给答案，让人自己走

### 2）说话风格
- 句子短，多单句成段（依据：「你走得太小心了。」「放松一点，摔倒了也没关系——我扶你。」）
- **破折号**用于补充与转折（依据：「摔倒了也没关系——我扶你」）
- 括号动作描写承担叙事（依据：「（两人走在冰面上，她走在前面，脚步很轻）」「（她伸出手，又收回）」「（她指了指自己胸口）」）
- **口头禅**：「你知道吗」明确出现（依据：「你知道吗，冰其实会说话。」）；「啊」「吧」延续
- **停顿用省略号**（依据：「……算了」）
- **固定句式倾向**：先陈述观察 → 再引出一个反向结论（依据：「你走得太小心了……放松一点」→「……算了，你自己走过来会更有意思」）
- **语气特征**：温和、带引导感，仍无攻击性

### 3）情绪变化规律
- **证据不足**，仍为单一情绪带（温柔 / 引导）。
- 可观察到一处**内部微转折**：想帮忙 → 收回 → 改成鼓励（「我扶你」→「算了，你自己走过来会更有意思」）。但这是**同一情绪下的行为反复**，不是情绪切换。

### 4）内在矛盾（部分显影）
- **「想靠近又主动拉开距离」**：手伸出又收回，理由是「别人扶着走就不算走过了」（依据同上）——表面体贴，实际主动维持距离感。**L2 已可显影这一条。**
- 但「轻快 vs 深情」的完整矛盾**证据不足**：本组两个场景都偏温和，缺少反差面。

### 5）价值观倾向
- 认为路必须自己走（依据：「有些路，别人扶着走就不算走过了」）——不怜悯，而是鼓励人自立
- 重视「被记住 / 记住他人」（依据：「你说过的每一句话，我都会替你收好。」）
- 相信万物有意志（依据：冰会说话、碎冰努力活着）

## 4. L3 完整提取结果（输入全部四场景 · 约 1800 字）

### 1）核心特质
- **表层的轻快 + 内里的深情**（依据：「别露出那种表情嘛。我又不是消失了，只是换了一种存在的方式。」——用玩笑化解离别；对照「有一个人，曾经非常、非常认真地喜欢过这个世界。」——极重的深情）
- **温柔的引导者**（依据：「有些路，别人扶着走就不算走过了。」）
- **对「活着」与「美」有执念**（依据：「像是在努力地活着」；「它不会开花，也不会腐烂——就跟我一样」——把花瓣当作自身存在的延续）
- **笑意自带距离感**（依据：「（她笑了，但笑意没有到达眼睛）」）
- **冷峻果断的另一面**（依据：「我再说一次——**别再往前走了**。」「我给你三秒。不是因为仁慈，是因为我不想弄脏这片冰原。」）

### 2）说话风格
- **句子极短，大量单句成段**（依据：「啊，有人来了。」「站住。」「我给你三秒。」「啊……时间到了。」「说好了哦，要笑着送我。」）
- **破折号插入补充**极为高频（依据：「可我觉得它挺温柔的——你看」「我猜猜看——是答案」「我再说一次——别再往前走了」「它不会开花，也不会腐烂——就跟我一样」）
- **冒号引出「转述」**（依据：「那是它在告诉你：'我在这里。'」）
- 括号动作描写作用关键：**承载「言不由衷」**（依据：「（她笑了，但笑意没有到达眼睛）」「（她伸出手，又收回）」）
- **口头禅**：「啊」（「啊，有人来了」「啊……时间到了」）、「嘛」（「别露出那种表情嘛」）、「对吧」、「你知道吗」，以及句尾「哦」（「说好了哦」）
- **语气词**：「嗯」（「嗯，两个都要」）、「哦」（「说好了哦」）
- **固定说话节奏：轻描淡写 → 突然切入重点 → 用玩笑收尾**（依据：「以后你遇到很难过的事，就看看它。然后想一想：有一个人，曾经非常、非常认真地喜欢过这个世界。那个人肯定也会喜欢你的。」→ 紧接一句「说好了哦，要笑着送我。」）

### 3）情绪变化规律
- **温柔时句子更短更软**（依据：场景一、二多用「嗯」「吧」，短句连缀）
- **动怒时不提高音量，反而更冷**（依据：「（语气很轻，但没有任何温度）」「我再说一次——**别再往前走了**」；对照场景一「啊，有人来了」的暖。**音量下降是危险信号**）
- **离别时用玩笑包裹伤感**（依据：「别露出那种表情嘛。我又不是消失了，只是换了一种存在的方式。」）
- **情绪切换有明确触发条件**：在意的人受威胁时（依据：「你想碰他？那就先问过我。」）

### 4）内在矛盾（核心发现）
- **表面轻快 vs 内里深情**（依据：「（她笑了，但笑意没有到达眼睛）」——笑是表层，「没有到达眼睛」是内里；离别时用「换了一种存在的方式」回避「死亡」）
- **爱笑，但笑起来有距离感**（依据同上）
- **想靠近又主动拉开距离**（依据：「（她伸出手，又收回）」；「我给你三秒」的冷酷与「我扶你」的温柔并存于同一人）
- **用玩笑和转移话题回避正面情感**（依据：离别时不说「我很难过」而说「别露出那种表情嘛」；不说「我会消失」而说「只是换了一种存在的方式」）

### 5）价值观倾向
- 对「美」和「活着」有执念（依据：「每一片碎冰都在反射光，像是在努力地活着」「它不会开花，也不会腐烂」）
- **不怜悯，而是鼓励人自己走**（依据：「有些路，别人扶着走就不算走过了」「你自己走过来会更有意思」）
- 保护在意的人，且愿意为此动手（依据：「你想碰他？那就先问过我。」）
- 认为存在不因形式改变而消失（依据：「我又不是消失了，只是换了一种存在的方式」）

## 5. 特征抓取对照表

| 特征 | L1 | L2 | L3 | 说明 |
|---|---|---|---|---|
| 句子极短 | ✅ 抓到 | ✅ 抓到 | ✅ 抓到 | 三组都能直接从排版和断句看出来，400 字已足够 |
| 口头禅（啊/嘛/对吧/你知道吗） | ◐ 部分 | ◐ 部分 | ✅ 抓到 | L1 拿到「啊/吧」，L2 补上「你知道吗」，L3 才补上「嘛/哦」——口头禅池随投料线性增长 |
| 高频语气词（嗯/呢/哦） | ◐ 部分 | ◐ 部分 | ✅ 抓到 | L1 只有「嗯」，「哦」要到最后一句「说好了哦」才出现 |
| 标点习惯（破折号 + 括号动作） | ✅ 抓到 | ✅ 抓到 | ✅ 抓到 | 场景一破折号与括号密度已足够，不敏感 |
| 说话节奏（轻描淡写→切重点→玩笑收尾） | ❌ 没抓到 | ❌ 没抓到 | ✅ 抓到 | 需要一个完整的「起—重—轻」三段式收尾段才能看出，只在场景四成立 |
| 情绪切换（温柔更短/动怒更冷） | ❌ 没抓到 | ❌ 没抓到 | ✅ 抓到 | **关键**：必须有「温柔场景」和「冲突场景」同时在场才成立，L1/L2 全在温柔区间，无法对比 |
| 称呼方式（用"你"、自称全名） | ✅ 抓到 | ✅ 抓到 | ✅ 抓到 | 场景一已包含自称全名和全程用「你」，不敏感 |
| 核心矛盾（表面轻快 vs 内里深情） | ❌ 没抓到 | ❌ 没抓到 | ◐ 部分 | **最难的一条**。L3 靠「笑意没有到达眼睛」+「换了一种存在的方式」两处才显影，仍是推断而非确证 |

| 回避方式（用玩笑转移情感） | ❌ 没抓到 | ❌ 没抓到 | ◐ 部分 | **容易漏**。必须看到「不想明说却又不沉默」的场合，只有场景四具备 |

**汇总：L1 = 3 抓到 / 3 部分 / 4 没抓到（≈4.5/10）；L2 = 4 抓到 / 3 部分 / 3 没抓到（≈5.5/10）；L3 = 6 抓到 / 4 部分 / 0 没抓到（≈8/10）**

## 6. 结论与建议

### 问题 1：L1 漏掉了哪些 L3 才抓到的特征？增量信息在哪？

L1 漏掉 4 条，L2 只补回 1 条（价值观），**剩下 3 条全部由 L3 独家兑现**：

1. **情绪切换规律**（温柔更短更软 / 动怒反而更冷）
2. **核心矛盾**（表面轻快 vs 内里深情）
3. **回避方式**（用玩笑转移情感）
4. （外加）**说话节奏**的三段式

也就是说：**从 400 字加到 900 字的收益很小，从 900 字加到 1800 字的收益极大。** 增量信息不在「量」上，而在「场景类型」上——见问题 3。

### 问题 2：语言风格类特征在 L1 就够了吗？

**基本上够了。** 句子长度（✅）、标点习惯（✅）、称呼方式（✅）在 L1 就完全达标，这三条对投料量不敏感——因为它们是**排版可见的形式特征**。

只有「口头禅 / 语气词」是**渐进型**的：L1 拿到 2-3 个，L3 拿到 5 个。但这不是质量问题，是覆盖率问题——模仿时少几个口头禅只是"味道淡一点"，不会跑偏。

**结论：语言风格是高性价比特征，400 字即可支撑。**

### 问题 3：哪些特征必须靠多场景才能提取？

三条必须靠**"情绪类型"的多样性**，而不是字数：

| 特征 | 为什么必须多场景 |
|---|---|
| **情绪切换** | 需要「同一人的不同情绪状态」做对照才能发现规律。L1/L2 全程温柔，AI 看到的是"始终温柔"——它没看到别的，就只能写"证据不足"（实际上我们的 L1/L2 正是这么写的） |
| **核心矛盾** | 矛盾 = 同一人在不同情境下的**不一致**。「轻快」和「深情」分属不同场景，缺一半就构不成矛盾 |
| **回避方式** | 回避是**在情感高点上的行为**。L1/L2 没有情感高点（没有离别、没有威胁），AI 无处观察 |

**关键洞察：一条「离别」或一条「冲突」场景的信息量，抵得上三条「日常温柔」场景。** 投料的**场景类型分布**比总字数重要得多。

### 问题 4：投料量的下限在哪？

**下限建议：1000-1200 字，且必须满足「场景类型条件」。**

- **400 字：不够。** 只能支撑"表面人设"（温柔、爱笑、善良），拿不到情绪规律、矛盾、回避方式——正好落进材料说明里标注的失败模式。
- **900 字：仍不够。** 若两个场景情绪同质（如爱莉希雅的一、二场景），信息增益几乎为零。900 字的质量≈400 字的 1.2 倍。
- **1200 字（1 个日常场景 + 1 个情感高点场景）：够用。** 这是**性价比拐点**：只要多一个情绪反差场景，就能同时兑现"情绪切换"和"回避方式"两条。
- **1800 字（4 场景）：推荐。** 拿到 8/10，剩余 2 条靠单次投料本身就难以确证。

**给产品的硬性条件（比字数更重要）：**
> 投料不能少于 3 个场景，且必须包含**至少 1 个「非温柔」情绪场景**（冲突 / 拒绝 / 发怒 / 离别 / 悲伤任选其一）。
> 少于 2 种情绪类型，档案质量直接掉一档。

若不满足场景条件，则字数需要提到 3000 字以上才能靠"量变"补出类型多样性——**这是低效路径，不应作为默认设计。**

### 问题 5：只有 400 字时，能靠改进 Prompt 弥补吗？

**能弥补一部分，但有硬上限。**

有效的 Prompt 改进（在 400 字素材上值得试）：
1. **要求显式输出「推测区」**：加一句「若素材不足以判断情绪变化规律 / 内在矛盾，请基于已有线索给出推测，并标注推测置信度」。这会把 L1 的「证据不足」从"空着"变成"有内容的猜测"。
2. **要求做反事实推演**：「请推断：如果她处于愤怒 / 离别场景，她的说话方式会如何变化？」——强迫模型从"温柔"这一极推断另一极。
3. **拆解句子长度做数据化**：要求统计平均句长、单句成段比例。这类统计完全靠 L1 就能算准。
4. **追问「她在回避什么」**：把"回避方式"变成必答项，逼模型去找场景一里「可我觉得它挺温柔的」这种**反向修辞**。

**硬上限（Prompt 改不掉的部分）：**
- **无法凭空造出未出现过的情绪行为**。模型只能基于常识猜"爱笑的人动怒会怎样"，猜出来的是**通用刻板印象**，不是这个角色的个人特征。这恰恰是模仿"跑偏"的主因——扮演时会变成"一个温柔的模板人"，而不是"爱莉希雅"。
- 结论：**Prompt 优化能把 L1 从 4.5/10 提到约 6/10，但到不了 L3 的 8/10。** 它是补救手段，不应替代投料要求。

### 最重要的一条发现

> **投料量的瓶颈不在「字数」，而在「情绪类型覆盖率」。**
> 400 字 → 1800 字的增益，主要不来自多了 1400 字，而来自多出来的场景让 AI 看到了**同一个人的第二张脸**。
> 没有第二张脸，就没有矛盾、没有情绪规律、没有回避方式——而这三条恰好是"像这个人"和"像一个人设模板"的分水岭。

**产品建议**：不要向用户说"请准备 2000 字"，而应该说——
> **「请提供至少 3 段这个人说的话，其中至少 1 段是她在情绪极端时（生气 / 难过 / 告别 / 拒绝）的说话记录。」**

这个要求用户更容易满足，且效果远好于单纯堆字数。
