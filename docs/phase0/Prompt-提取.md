# 提取 Prompt（两版对照）

> 用途：Phase 0 步骤 2
> **直接复制整段**粘贴到 LLM 对话框，再把素材贴在 `<素材>` 处

---

## 为什么给两个版本

这是本次验证的核心变量。**不是"哪个 Prompt 更好"，而是"两种问法的失效模式分别是什么"。**

| 版本 | 思路 | 预期优点 | 预期失效模式 |
|---|---|---|---|
| **v1 总结式** | 让 AI 通读全文，总结出人设 | 输出结构清晰、可读性好 | 容易输出"正确的废话"（温柔、善良、爱笑） |
| **v2 考证式** | 禁止总结，只准摘录原文做归纳 | 逼 AI 回到证据，难以编造 | 输出冗长、碎片化，可能失去整体感 |

跑完两版对比，就知道**最终产品该用哪种**，或者是否要混合。

# ✅ v1 · 总结式（先跑这个）

```
你要从下面这段素材中，提取一个人的「人格档案」。

素材是这个人在不同场景下说过的话（含动作和场景描写）。
你的任务不是写角色介绍，而是提取出「能让另一个人模仿她说话」的具体信息。

输出结构：

## 一、核心特质（冻结层）
- 性格关键词：3-5 个，每个词后面用一句话说明依据
- 价值观倾向：她自然亲近什么样的人/事，排斥什么
- 内在矛盾：她身上有没有「表面是什么样、实际是什么样」的反差

## 二、说话风格（冻结层）
- 句子长度倾向：短句/长句/长短交替，给个大致字数范围
- 标点习惯：特别注意破折号、省略号、括号的使用
- 口头禅 / 高频词：列出素材中出现 2 次以上的词或语气词
- 语气特征：
- 情绪变化时的差异：她开心 / 生气 / 难过时，说话方式分别有什么不同
- 表达习惯：喜欢反问？先铺垫再表达？用玩笑回避正题？

## 三、称呼与关系（冻结层）
- 她怎么称呼对方：
- 她如何定义自己与对方的关系：
- 她如何称呼自己：

## 四、证据（重要）
每一条结论后面，必须附上素材中的**原文片段**作为依据。
如果某一条你没有把握，写「证据不足」，不要猜测。

## 五、模仿指令
用 3-5 句话，写一段「给扮演者的指令」——告诉一个完全不了解她的人，
要怎样说话才会像她。要具体到可操作，不要写"要有感情"这种空话。

素材：
<在此粘贴素材>
```

# ✅ v2 · 考证式（跑完 v1 再跑这个）

```
你的任务：从下面的素材中，为「模仿这个人说话」收集证据。

**禁止做整体性的性格总结。** 只做一件事：
把素材中的语言特征逐条摘录出来，每条都要有原文。

输出格式（只输出这个，不要加开场白和总结）：

| # | 观察到的特征 | 原文证据 | 我的推断 |
|---|---|---|---|
| 1 | | 「」 | |
| 2 | | 「」 | |
...

要求：
1. 至少摘录 15 条，宁可多不要少
2. 每条证据必须是素材里的**逐字原文**，不许改写
3. 「我的推断」一栏写：这个语言习惯说明了她是什么样的人
4. 优先关注这些方面：语气词、句子长度、标点、称呼方式、
   情绪变化、回避方式、开玩笑的方式
5. 如果某类特征你在素材里找不到，明确写「未观察到」，不要硬凑

摘录完后，单独回答三个问题：

**Q1** 素材里有没有「她说的话和她实际想法不一致」的地方？举出证据。
**Q2** 她对不同的人说话方式有区别吗？如果没有，说明什么？
**Q3** 如果只允许你保留 3 条特征来描述她的说话风格，你保留哪 3 条？为什么？

素材：
<在此粘贴素材>
```

# 🔍 跑的时候重点看什么

不要只打分了事。跑的过程中留意这几个信号：

| 观察点 | 说明 |
|---|---|
| **会不会编** | 证据栏里有没有素材里根本不存在的句子？这是最严重的失败 |
| **会不会说废话** | 出现"她是一个独特而有魅力的人"这类 → 直接扣分 |
| **敢不敢说"不知道"** | v2 要求写"未观察到"，如果它硬凑 → 说明约束不够强 |
| **有没有抓到反差** | "表面轻快 vs 内里深情"是核心考点，抓不到说明只读了表层 |
| **模仿指令能不能用** | 第五节写得越具体，说明它理解得越深 |
