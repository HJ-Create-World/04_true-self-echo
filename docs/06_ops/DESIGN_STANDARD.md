# 视觉规范

> **什么时候读这份文档**：写任何界面代码之前；review UI 时；不确定某个颜色/圆角/阴影该用什么值时。
>
> **它不是**：技术选型的原因（那是 `02_decisions/D008`），也不是组件该怎么组织（那是 `03_specs/`）—— 它只给**可照抄的取值和禁止项**。
>
> **它能回答**：背景色是什么？圆角用几档？hover 该怎么动？哪些 class 绝对不能用？怎么自查没跑偏？

---

## 〇、结论先行

1. **本项目视觉风格 = 水彩画风（Watercolor）**，来源为 stylekit.top 的 watercolor-style 模板规范。
2. **实现载体 = Tailwind CSS v4 + 一组语义化 CSS 变量**。规范本身就以 Tailwind class 形式给出，因此**直接用 Tailwind 是最短路径**（决策与代价见 `D008`）。
3. **五条铁律**：不用纯黑 / 不用硬边框 / 不用直角 / 不用高饱和 / 不用 `font-bold`。
4. **动效四规则**：颜料晕开、湿纸效果、液态缓动、柔和按压。**其中「液态缓动」和「柔和按压」是强制项，漏了就是跑偏。**
5. 配套自检清单在 §六，**提交 UI 代码前逐条过一遍**。

## 一、设计 Token 字典（唯一信息源）

> ⚠️ **本节是取值的唯一信息源。** 别的文档只能引用本节，不能复制一份自己的色板。
> 落地方式：把 §1.1–§1.4 的值写进 `tailwind.config` 或 `@theme` 块，**代码里禁止出现本节之外的魔法色值**。

### 1.1 色彩

| 语义 | 值 | Tailwind 写法 | 用途 |
|---|---|---|---|
| 纸张底色 | `#faf8f5` | `bg-[#faf8f5]` | 页面根背景。**不要用 `bg-white`** |
| 正文主色 | `#3a3a3a` | `text-[#3a3a3a]` | 正文文字。**不要用 `#000`** |
| 水彩蓝灰（辅/主强调） | `#4a6fa5` | `text-[#4a6fa5]` | 标题、链接、聚焦态、阴影基色 |
| 蜜桃 | `#e8a87c` | `text-[#e8a87c]` | 强调点缀、次要标签 |
| 青绿 | `#85cdca` | `text-[#85cdca]` | 成功态、正面指标 |
| 玫瑰 | `#c38d94` | `text-[#c38d94]` | 警示、删除、负面指标 |
| 沙色 | `#d4a373` | `text-[#d4a373]` | 中性点缀、分隔元素 |

**半透明叠加（营造水彩层次，不用实色铺满）**：

| 用途 | 写法 |
|---|---|
| 卡片 / 面板 | `bg-white/60` |
| 输入框 | `bg-white/60` |
| 弱分隔线 | `border-[#4a6fa5]/15` |
| 悬停背景 | `bg-[#e8a87c]/10` |

> 📌 **透明度上限 0.15 用于装饰元素**（`DEV_STANDARD.md` 审美约束）。
> 背景纹理、水彩晕染等**纯装饰层**不透明度不得超过 0.15，不得压过内容可读性。

### 1.1.1 柔光色域层（已定版的实现）

页面背景由**两层纯装饰层**构成，均 ≤ 0.15：

| 层 | 选择器 | 职责 | 实测值 |
|---|---|---|---|
| 柔光色域 | `body::before` | 情绪氛围 | `opacity: 0.12` + `mix-blend-mode: soft-light` |
| 纸纹噪点 | `body::after` | 纤维质感 | `opacity: 0.035`，纯白噪点 5 层错位 |

**四套情绪主题**（`<body data-theme="...">` 切换）：

| 主题 | 色相倾向 | 光斑布局 |
|---|---|---|
| `dawn` 黎明 | 冷蓝破晓 + 暖橘微光 | 上轻下重 |
| `tide` 潮汐 | 青绿主导 | 横向流动，中间亮带 |
| `dusk` 黄昏 | 蜜桃 + 玫瑰 | 暖重压下方 |
| `garden` 花园 | 青绿左 + 浅粉右 | 对比最低（默认） |

> 🔴 **想加强背景存在感时，不要动 `opacity`。**
> 上限管的是**浓度**，不是**存在感**。改为调这三项：
> ① 色相 ② 光斑的位置与半径（`--p1..--p4` / `--r1..--r4`，**大面积、更糊 ≠ 更浓**）
> ③ 混合模式。完整论证与反例见 `02_decisions/D009-原型定版与背景切换机制.md` §三。

> 📌 **调背景强度只需改一个变量**：`--field-opacity`（当前 `0.12`）。四套主题同步生效。

### 1.2 圆角

| 档位 | 写法 | 用途 |
|---|---|---|
| 大容器 / 卡片 | `rounded-2xl md:rounded-3xl` | 面板、对话气泡、弹窗 |
| 按钮 / 输入框 | `rounded-2xl` | 交互控件 |
| 小标签 | `rounded-full` | 徽章、pill |

> 🔴 **禁止 `rounded-none` 与 `rounded-sm`。** 本项目全部元素至少有 1rem 圆角。
> 具体到实现：如果某处必须收窄，用 `rounded-xl`，不要更小。

### 1.3 阴影

| 档位 | 写法 | 用途 |
|---|---|---|
| 常态 | `shadow-[0_4px_20px_rgba(74,111,165,0.12)]` | 卡片、气泡 |
| 悬停（颜料晕开） | `shadow-[0_10px_40px_rgba(74,111,165,0.35)]` | 卡片 hover |
| 聚焦 | `ring-2 ring-[#4a6fa5]/30` | 输入框 focus |

> 🔴 **禁止硬阴影**（正则为 `shadow-\[\d+px_\d+px_0px`，如 `shadow-[4px_4px_0px_...]`）。
> 阴影必须是**大模糊半径 + 低透明度**，模拟颜料在纸上的扩散，不是 UI 卡片投影。

### 1.4 字体与排版

| 项 | 写法 |
|---|---|
| 字族 | `font-serif`（**必须衬线**，模拟纸面书写感） |
| 字重 | `font-light` / `font-normal`；标题用 `font-normal` |
| 字距 | `tracking-wide` |
| 标题字号 | `text-3xl md:text-4xl` |
| 正文行高 | `leading-relaxed` |

> 🔴 **禁止 `font-bold` / `font-black` / `font-extrabold`。**
> 层次靠**字号 + 颜色 + 字距**拉开，不靠加粗。

### 1.5 动效参数

| 项 | 值 | 说明 |
|---|---|---|
| 缓动曲线 | `ease-out` / `ease-in-out` | **禁止 `ease-linear`** |
| 时长 | `duration-400` / `duration-500` | **禁止 `duration-150` 及更短** |
| 卡片悬停 | `hover:scale-[1.02]` | 配合阴影加深 |
| 按压 | `active:scale-[0.98]` | **强制**，所有可点击元素 |

## 二、动效四规则（缺一即跑偏）

| # | 名称 | 做法 | 反例 |
|---|---|---|---|
| 1 | **颜料晕开** | hover 时**只加深阴影**：`hover:shadow-[0_10px_40px_rgba(74,111,165,0.35)]` | ❌ 用 `hover:-translate-y-1` 把卡片"抬起来" —— 那是科技风，不是水彩 |
| 2 | **湿纸效果** | hover 时背景**微提亮**：`hover:bg-white/80`（或 `hover:bg-[#faf8f5]/70`） | ❌ 背景直接换成另一个实色 |
| 3 | **液态缓动** | 统一 `transition-all duration-500 ease-in-out` | ❌ `duration-150`（生硬）、`ease-linear`（机械） |
| 4 | **柔和按压** | `active:scale-[0.98]` + 内阴影反馈 | ❌ 无按压反馈，或用了 `active:scale-95`（过猛） |

**标准交互元素骨架**（照抄这个，别自由发挥）：

```html
<button
  class="rounded-2xl bg-white/60 font-serif font-light tracking-wide text-[#3a3a3a]
         px-6 py-3
         shadow-[0_4px_20px_rgba(74,111,165,0.12)]
         transition-all duration-500 ease-in-out
         hover:shadow-[0_10px_40px_rgba(74,111,165,0.35)]
         hover:bg-white/80 hover:scale-[1.02]
         active:scale-[0.98]
         focus:outline-none focus:ring-2 focus:ring-[#4a6fa5]/30">
  按钮文字
</button>
```

## 三、禁止项（可用正则直接扫）

以下正则命中即为违规。建议接进 lint 或提交流程。

| # | 正则 | 拦截 | 为什么 |
|---|---|---|---|
| 1 | `^rounded-none$` | 直角 | 水彩无硬边 |
| 2 | `^shadow-\[\d+px_\d+px_0px` | 硬阴影 | 阴影必须弥散 |
| 3 | `^border-(?:black\|2\|4)$` | 硬边框 | 边界靠明暗与留白，不靠描边 |
| 4 | `^font-(?:black\|bold)$` | 超粗字重 | 破坏纸面书写感 |
| 5 | `^bg-(?:black\|\[#1a1a)` | 纯黑背景 | 纯黑会把水彩"压死" |

> ⚠️ 允许的边框例外：`border border-[#4a6fa5]/15` 这类**极低透明度细线**，
> 用于表格分隔或弱分区。注释掉原因再写。

## 四、必含项（漏了说明没用规范）

写任何新页面/新组件时，以下五项**必须出现**：

- [ ] **根背景** `bg-[#faf8f5]`（纸张色）
- [ ] **正文颜色** `text-[#3a3a3a]`（不是 `text-black`）
- [ ] **至少一处强调用色**：`#4a6fa5` / `#e8a87c` / `#85cdca` / `#c38d94` / `#d4a373`
- [ ] **所有可点击元素**带 `transition-all duration-500` + `active:scale-[0.98]`
- [ ] **衬线字体** `font-serif` + `tracking-wide`

---

## 五、配色使用倾向（本项目特有，不是模板原文）

水彩模板给了 5 个强调色。**本项目不要用满**，按下方倾向分配，避免变成花布：

| 色 | 本项目用途 | 用量 |
|---|---|---|
| 蓝灰 `#4a6fa5` | **主色**：标题、链接、聚焦、结构线 | 主 |
| 蜜桃 `#e8a87c` | **第二主色**：强调按钮、当前选中项 | 次 |
| 青绿 `#85cdca` | **正向指标**：评分达标、实验成功 | 点缀 |
| 玫瑰 `#c38d94` | **负向指标**：评分不达标、被否决的方案 | 点缀 |
| 沙色 `#d4a373` | **中性标记**：待办、未验证 | 点缀 |

> 📌 **映射到本项目语义**：人格评分六维用蓝灰；两条红线（不得变激动 / 不得追问并长篇安慰）
> 命中时用玫瑰；通过时用青绿。这样评测结果一眼能看懂（见 `03_specs/评分标准.md` §九）。

## 六、提交前自检清单

写 UI 代码的人（或 AI）在提交前逐条确认：

- [ ] 背景用了 `bg-[#faf8f5]`，没有 `bg-white` 直接铺满整页
- [ ] 正文用了 `text-[#3a3a3a]`，没有 `text-black` / `text-gray-900`
- [ ] 没有出现 §三表格里的 5 个禁止正则
- [ ] 圆角 ≥ `rounded-2xl`（小标签除外，可用 `rounded-full`）
- [ ] 阴影是弥散型（大模糊 + 低透明度），不是 `4px 4px 0px` 型
- [ ] 所有 hover 都改的是**阴影和背景**，没有用 `translate-y` 抬卡片
- [ ] 所有过渡 ≥ `duration-400`，缓动是 `ease-out`/`ease-in-out`
- [ ] 所有可点击元素有 `active:scale-[0.98]`
- [ ] 字体是 `font-serif`，没有 `font-bold`
- [ ] 装饰性背景层不透明度 ≤ 0.15
- [ ] 强调色没有 5 个一起上，按 §五 的倾向分配

## 七、已知约束与风险

| 项 | 说明 |
|---|---|
| **分辨率下限** | 该风格留白多、字号大，**< 375px 宽度会挤**。移动端优先保证 375px 可用 || **对比度** | `#3a3a3a` on `#faf8f5` 对比度约 10.9:1，达标；但 `#85cdca` 等浅色**不可用作正文**，仅作点缀 |
| **暗色模式** | **本阶段不做**。水彩风格的暗色版需要重新定义整套纸感，不划算（见 `D008`） |
| **无障碍** | ✅ **原型 v0.2 已补**：胶囊组用 `role="radiogroup"` + `aria-checked`，支持方向键；全局 `prefers-reduced-motion` 降级（见 `D009` §4.2） |
| **未获取项** | 模板原站未提供无障碍（a11y）检查结果；本规范的对比度数值为本地计算，非官方数据 |
| **像素下限** | 规范给的下限是 375px，但**原型只在桌面宽度确认过**，未做真机移动端测试 |
