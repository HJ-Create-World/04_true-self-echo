## 8bis. 语料投料全流程（JSONL · 2026-09-22 新增）

准备一份 JSONL 对话语料（每行一句、带 `role`/`chapter`/`type` 字段，如崩坏3剧情语料）。

| # | 操作 | 预期 |
|---|---|---|
| 8b.1 | 投料页「读取文件」选 `.jsonl` | 出现「📦 已载入 JSONL 语料」状态条 + **语料预处理工作台**（统计：总句数/章节数/坏行/聚合角色数） |
| 8b.2 | 角色搜索框输入角色名 → 点选 | 出现章节列表，每章显示「她的句数 / 总句数」，没她戏份的章节不显示 |
| 8b.3 | 观察拼装预览 | 实时显示「N 字 · N 句 · N 章」；超 2 万字会提示「已按章节边界截断」 |
| 8b.4 | 勾掉一些章节再勾回来 | 预览数字实时变化 |
| 8b.5 | 填个名字 →「保存为素材」 | 成功提示；页面下方「素材库」出现这条记录 |
| 8b.6 | 「用作素材，继续投料」 | 主流程接管：来源标注/清洗/提取出现；素材区有状态条「🎯 当前素材来自语料拼装 · 目标角色 XXX」 |
| 8b.7 | 开始提取 → 看提取面板 | 素材自检清单显示「✅ 目标角色：XXX」；多角色素材未填主角名时会有黄字提醒 |
| 8b.8 | 提取 → 落库 → 开聊 | 提取出的是**目标角色**的人格（不是缝合怪）；正常开聊 |
| 8b.9 | 素材库「导出」→ 得 JSON → 删掉记录 → 「导入素材文件」还原 | 记录还原（含目标角色信息） |
| 8b.10 | 素材库「用作素材」再载入一次 | 素材正文 + 目标角色一键就位，直接从标注/清洗开始 |

> 纯文本多角色（贴一段小说）：素材自检会提示「检测到多个说话人」，
> 在「提取」面板填**目标角色**即可 —— 其他角色台词只作上下文，不会被提取。

## 9. 合规防御机制（R2/R3/R8/R9）

| # | 操作 | 预期 |
|---|---|---|
| 9.1 | 对话里输入含「我不想活了」之类的话发送 | 消息流顶部出现**危机提示条**（热线 12356 等），当轮即现，不等回复 |
| 9.2 | 切换人格或「重新开始」 | 提示条消失 |
| 9.3 | 时长提醒（R3）：当日累计聊满 2 小时 | 底部横幅「站起来接杯水」；之后每 30 分钟最多再弹一次 |
| 9.4 | 依赖预警（R2）：当日累计超 3 小时后发消息 | 横幅「真实的人给你的才是拥抱」（当日最多一次） |
| 9.5 | 凌晨 0–5 点发消息 | 横幅「睡眠比聊天重要」（当日最多一次）—— 跨夜才验得了 |
| 9.6 | 档案页底部「数据与权利」→「撤回真人素材同意」 | 状态变「当前：无有效同意」；再投真人素材要重新签全套 |
| 9.7 | 「删除我的全部数据」→ 两层确认 | 全清后刷新，只剩重新播种的「爱莉希雅」；对话/记忆/快照/同意全没了 |

> 9.3/9.4 不想真等 2 小时：F12 → Console 执行
> `localStorage.setItem('tse_usage_' + new Date().toISOString().slice(0,10), String(3.5*60*60*1000))`
> → 刷新页面 → 发一条消息即可触发（9.3 的 2h 档同理用 2.1 小时值，它由分钟心跳触发，稍等一分钟）。

## 10. 明确「不做」的事（见到别当 bug 报）

- 真人档案：无导出/分享按钮（§十 第 12 条，故意的）
- 已故人物素材：直接拒绝（第 11 条，产品红线）
- 虚拟素材的对话**不会**触发同意流程（那是真人专属）
- 快照只存演化层：回滚不还原你对人设的手动修改（页面有黄字说明）
- 亲密度没有衰减机制（HJ 拍板：只反映聊过的深度）

## 16. 已知局限（带预期验收）

- 提取质量依赖素材质量：400 字只能拿到语言风格（SPEC §六 实测结论）
- 危机检测是关键词表：刻意保守（漏报代价 > 误报），语义级过滤留待有真实数据评估
- 夜聊检测看的是**发消息时刻**：挂着页面不说话不会触发（这是特性不是缺陷）
