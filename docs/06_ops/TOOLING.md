# Skill 与 MCP 清单

> 状态：v1.0 · 最后更新 2026-09-16
> 说明：本文件列出完成本项目**可能用到**的外部能力，并给出安装建议。是否安装由 HJ 决定。
> 判断标准：**能少装就少装。** 装多了既占上下文又增加不确定性。

---

## 一 · 结论先行

| 分类 | 是否需要 | 结论 |
|---|---|---|
| 必备 MCP | 无 | 现有 GitHub 连接器 + 本地 git 已够用 |
| 建议安装的 Skill | 1 个 | `agent-browser`（Phase 3 之后调试用得上） |
| 可选 | 2 个 | `find-skills`（找能力）、`skill-creator`（沉淀流程） |
| **不要装** | — | 各种「全能 Agent」「自动化平台」类 Skill |

**核心判断**：这个项目的技术栈是 Vue3 + TS + Vite + 一个薄后端，全部是标准 Web 开发。标准 Web 开发不需要特殊 Skill，需要的是你自己看懂代码。

## 二 · MCP 清单

### 已连接，直接可用

| MCP | 状态 | 在本项目中的用途 |
|---|---|---|
| **GitHub** | ✅ 已连接 | 查开源项目、看别人的实现（**只读**） |
| **Agent Mail** | ✅ 已连接 | 本项目暂时用不到 |

### ⚠️ 重要提醒：GitHub MCP 不能推代码

GitHub 连接器**只有读权限**，任何写操作（建仓库、提交文件）都会返回 403 `Resource not accessible by integration`。

**推代码一律走本地 git**，配置方案见 `06_ops/RUNBOOK.md`。这个坑已经踩过，别再试。

### 不需要额外安装的

| 看起来需要 | 为什么不需要 |
|---|---|
| 文件系统 MCP | WorkBuddy 自带文件读写能力 |
| 浏览器 MCP | 有 `agent-browser` Skill 就够，不用额外 MCP |
| 数据库 MCP | 本项目数据存本地（IndexedDB / JSON 文件），没有数据库 |
| 语音合成 MCP | Phase 5 才涉及，且走 HTTP 调用，不需要 MCP 包装 |

## 三 · Skill 清单

### 建议安装：`agent-browser`

| 项 | 内容 |
|---|---|
| 用途 | 浏览器自动化：打开页面、截图、抓取内容、点击元素 |
| 本项目用在哪 | Phase 2 之后的**调试**：自动打开本地页面、截图看布局、批量验证交互路径 |
| 为什么值得 | 你自己在浏览器里手点也行，但改一次代码就要手点一遍很烦。有了它可以让 AI 自己截图看效果，反馈闭环更短 |
| 何时装 | **Phase 1 完成、页面能跑起来之后再装**。现在装没用 |
| 安装方式 | 在对话里说「安装 agent-browser skill」 |

### 可选：`find-skills`

| 项 | 内容 |
|---|---|
| 用途 | 当你需要某个能力但不知道有没有现成 Skill 时，先搜一下 |
| 何时用 | 遇到「这个我好像做不了」的场景时 |
| 评价 | 装了不亏，占用很小。但它本身不提供能力，只是搜索入口 |

### 可选：`skill-creator`

| 项 | 内容 |
|---|---|
| 用途 | 把重复的工作流沉淀成 Skill |
| 本项目用在哪 | **不是给这个项目用的，是给「开发规范」用的** —— 如果你发现每次让 AI 干活都要重复交代同一套规矩，可以做成 Skill |
| 评价 | 优先级低。等真的出现重复劳动再说 |

### 明确不建议装的

| Skill 类型 | 为什么不装 |
|---|---|
| 各种「全自动 Agent / 工作流平台」 | 与本项目的「薄、可控、自己看得懂」原则冲突 |
| 低代码/可视化搭建类 | 生成的东西你看不懂，正好踩中烂尾模式 |
| 任何会自动改多个文件的「重构助手」 | 在项目早期，不确定性 > 效率 |

## 四 · 本项目真正的「工具需求」

不是 MCP 也不是 Skill，而是这几样，比上面所有东西都重要：

| # | 需求 | 怎么满足 |
|---|---|---|
| 1 | 一个能用的 LLM API（带 Key） | 已经确认：本地 + 云端双选，云端走 OpenAI 兼容接口 |
| 2 | 一个本地模型运行时（可选） | Ollama，装了就能用，不装也不影响主流程 |
| 3 | 一个称手的 Prompt 调试环境 | 网页版 LLM 就够，Phase 0 全程用它 |
| 4 | **AI 协作的规矩**（最重要的「工具」） | [DEV_STANDARD.md](./DEV_STANDARD.md) §五 |

第 4 条是真的「工具」——它决定了每次和 AI 协作产出的代码是资产还是负债。
