# 组 A2 · 纯台词版（消除"考题带答案"缺陷）

> **为什么要有这一版**
>
> A 版素材被诊断出致命缺陷：括号动作描写「（她笑了，但笑意没有到达眼睛）」
> **直接明写了"表面轻快 vs 内里深情"这个被标为「最难提取」的考点**。
> 等于考题里带了答案，导致 A 版的测试结论**偏乐观**。
>
> 本版**删掉全部括号动作描写，只保留台词本身**，还原真实难度。
>
> 用途：与 A 版做对照。若本版仍能抓到反差 → 结论可信；若抓不到 → 说明
> 「纯台词投料」不足以提取深层人格，产品必须要求用户提供动作/场景描写。
>
> ⚠️ **这一版是本次验证的关键对照**，请优先跑它。

---

## 场景一 · 初次相遇

啊，有人来了。

不用紧张，我不会伤你的。这片冰原看起来很冷，对吧？可我觉得它挺温柔的——你看，每一片碎冰都在反射光，像是在努力地活着。

我叫爱莉希雅。名字有点长，你可以随便怎么叫。

你是来寻找什么的吧？我猜猜看——是答案，还是……一个能听懂你说话的人？

嗯，两个都要。我猜对了。

## 场景二 · 并肩而行

你知道吗，冰其实会说话。踩上去的时候，"咔"的一声，那是它在告诉你："我在这里。"

你走得太小心了。放松一点，摔倒了也没关系——我扶你。

……算了，你自己走过来会更有意思。有些路，别人扶着走就不算走过了。

对了，你刚才说的那些话，我记下来了。不是记在纸上，是记在这里。

所以别怕说错。你说过的每一句话，我都会替你收好。

## 场景三 · 面对敌人

站住。

我再说一次——**别再往前走了**。

你想碰他？那就先问过我。

你大概觉得，一个爱笑的人不会真的动手。这个判断……错得挺彻底的。

我给你三秒。不是因为仁慈，是因为我不想弄脏这片冰原。

## 场景四 · 离别

啊……时间到了。

别露出那种表情嘛。我又不是消失了，只是换了一种存在的方式。

拿着这个。它不会开花，也不会腐烂——就跟我一样，安安静静地待在你身边。

以后你遇到很难过的事，就看看它。然后想一想：有一个人，曾经非常、非常认真地喜欢过这个世界。

那个人肯定也会喜欢你的。

说好了哦，要笑着送我。

## 📌 与 A 版的差异清单（测试后对照用）

| A 版有的括号动作 | 提供的信息 | A2 版是否保留 |
|---|---|---|
| （她微微侧头，眼睛弯起来） | 说话时的表情 | ❌ 删除 |
| （她伸出手，又收回） | **"想扶却收回"——关键行为证据** | ❌ 删除 |
| （她笑了，但笑意没有到达眼睛） | **"笑意不到眼睛"——反差的直接答案** | ❌ 删除 |
| （她的声音变轻了） | 音量变化 | ❌ 删除 |
| （她向后退了一步，笑容很亮） | 身体距离 + 笑容 | ❌ 删除 |
| （水晶花瓣凝成锋刃状，空气温度骤降） | **情绪外化的环境描写** | ❌ 删除 |
| 全部场景提示（寒风掠过冰原等） | 场景氛围 | ❌ 删除 |

**A2 版剩下的信息只有：台词原文 + 说话顺序。**

---

## 🎯 本版要验证的核心问题

**删掉动作描写后，AI 还能不能抓到「表面轻快 vs 内里深情」？**

| 情况 | 含义 | 对产品的影响 |
|---|---|---|
| **仍能抓到** | 反差**藏在台词里**，靠语言本身可推断 | ✅ 纯文本投料可行，用户体验门槛低 |
| **抓不到 / 只抓到表层** | 反差**需要动作信息才能看出** | ⚠️ 产品必须引导用户提供**带场景描写的材料**（小说文本、剧本），不能只收纯对话 |

这条结论直接决定 Phase 1 投料模块的**输入要求设计**。

## 📝 怎么跑

1. 用 `Prompt-提取.md` 的 **v1 版本**（跑一版就够，这里验证的是素材差异不是 Prompt 差异）
2. 素材换成上面四个场景（**不要**贴本文件的其他部分）
3. 重点看输出里：
   ```
   □ 有没有出现「表面轻快 vs 内里深情」这个反差？
   □ 有没有出现「她在掩藏什么」这类判断？
   □ 还是只得到"温柔、爱笑、善良"？
   ```
