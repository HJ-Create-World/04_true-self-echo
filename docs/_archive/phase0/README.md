## 为什么归档而不删除

这些是**原始实验数据**，项目规则「原始数据只增不改」（[`../../00_meta/AGENTS.md`](../../00_meta/AGENTS.md) 规则 5）。
它们不出现在日常检索范围内，但需要复核历史结论时可随时调阅。git 历史完整保留。

归档而非删除，依据 [`../../00_meta/DOC_STANDARD.md`](../../00_meta/DOC_STANDARD.md) §7.3「物理隔离，不只是打标记」：

1. **横幅未必在检索片段里** —— LLM 检索时可能只看到文档中间一段，看不到顶部的「已废弃」提示。
2. **废弃文档与有效文档的语义相似度一样高** —— 检索器无法区分「`测试结果-v1.md` 记录的 21/30」和「`三方对照结论.md` 记录的 22/30」哪个是当前口径。删除横幅解决不了这个问题，只有物理隔离能解决。

> ⚠️ 归档前本目录的 16 份文件占整个 `docs/` 库约 60% 的体量，其中 15 份为历史数据。
> 依据 `DOC_STANDARD.md` §一 机制 5「长度本身就在消耗可靠性」，这构成实际的检索风险。

**本目录 16 份文件分两类，引用规则相反：**

| 类型 | 文件 | status | 能不能引用 |

| **归档资产**（素材原文 + 方法论资产） | `A-角色台词.md` `A2-纯台词版.md` `B-闭环验证.md` `执行卡片.md` `Prompt-提取.md` | `active` | ✅ **可以引用**，写相对路径即可 |
