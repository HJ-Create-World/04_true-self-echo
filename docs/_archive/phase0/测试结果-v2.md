**Q1** 素材里有没有「她说的话和她实际想法不一致」的地方？举出证据。

有，而且至少 4 处，且都集中在"她要伸手、又收回"这个动作上。

1. **说"我扶你"，紧接着不许自己被扶。**
   先说：「摔倒了也没关系——我扶你。」（「我扶你。」三个字是她最短、最不含修饰的句子，最像真心话）
   紧接着：「（她伸出手，又收回）」「……算了，你自己走过来会更有意思。有些路，别人扶着走就不算走过了。」
   ——括号里的"又收回"是最直接的证据：她的手说的和她的嘴说的相反。她说出的理由是"你自己走更有意思"，但她真正的动作是没舍得。

2. **说"我又不是消失了"，但她的身体正在变透明。**
   场景四的舞台提示是「（她站在光里，身体边缘开始变得透明）」，而她的台词是「别露出那种表情嘛。我又不是消失了，只是换了一种存在的方式。」
   ——她在用"换了一种方式"改写一个正在发生的、不可逆的消失。这句话本质上是对对方、也是对自己说的安慰，而不是事实陈述。

3. **说"要笑着送我"，但全篇最重的一句话就在前面。**
   她刚说完「有一个人，曾经非常、非常认真地喜欢过这个世界。」然后立刻是「（她向后退了一步，笑容很亮）」「说好了哦，要笑着送我。」
   ——"笑容很亮"和"说好了哦"都是她的表演指令。她要求对方笑，是因为她自己必须靠这个要求才撑得住；她给出的轻松是一个她需要对方配合才能维持的轻松。

4. **说"一个爱笑的人不会真的动手"这个判断错得彻底，等于承认自己的笑是工具。**
   「你大概觉得，一个爱笑的人不会真的动手。这个判断……错得挺彻底的。」＋「（她笑了，但笑意没有到达眼睛）」
   ——她自己主动点出"笑"和"真"之间的落差。这说明她平时呈现的轻松，是她有意维持的。

**Q2** 她对不同的人说话方式有区别吗？如果没有，说明什么？

**几乎没有区别，而且这种"没有区别"本身是可疑的。**

证据：素材中出场的有两类对象——同伴（场景一、二、四）和敌人（场景三），但她对两类人都只用一个词「你」，从不叫名字，也从不改变称呼。
- 对同伴：「不用紧张，我不会伤你的。」
- 对敌人：「你想碰他？那就先问过我。」

区别只出现在**参数**上，不在**称呼和句式**上：
- 句子变短：从场景二的「你走得太小心了。放松一点，摔倒了也没关系——我扶你。」压到场景三的「站住。」
- 温度词消失，出现明确的规则和期限：「我给你三秒。」
- 括号提示从柔软的动作（「她伸出手，又收回」）换成敌意的动作（「水晶花瓣在她身周凝成锋刃状」）

也就是说：**她不是对亲近的人换一套语言，而是对所有人用同一套语言，只调冷淡程度。**

这说明三件事：
1. 她的"温柔"不是社交面具，是她的默认设置——她对外人、对敌人、对朋友打开的都是同一个界面，所以她显得稳定，也因此显得有距离。
2. 她的人格结构里"亲近"和"敌意"不是两种模式，而是同一种模式的两种强度。这与第 21 条（生气时不提高音量）互相印证：**她的开关是"温度"，不是"音量"。**
3. 素材中缺少她"示弱""求助""被人安慰"的场景，所以无法判断她这一面是否也这么统一——这一点是**证据不足**，不能下结论说她对所有人都一样。

**Q3** 如果只允许保留 3 条特征来描述她的说话风格，保留哪 3 条？为什么？

1. **第 38 条：稳定的三段结构——真实情感 → 收住（…／算了／嘛）→ 玩笑或软要求。**
   理由：这是唯一一条能解释她"为什么听起来又轻又重"的结构性特征。只学语气词学不会她，学会这个结构才能像她。它同时覆盖了第 16、17、29、30、37 条。
2. **第 21 + 26 条：情绪不通过音量表达，通过温度和外部世界表达。**
   理由：这是她最强的辨识度。她愤怒是「（语气很轻，但没有任何温度）」＋「空气温度骤降」，难过是「身体边缘开始变得透明」。如果扮演者按照"生气就大声"来演，会立刻不像她。合并为一条：**情绪由环境和温差承载，语言本身保持低压。**
3. **第 28 + 32 条：只用「你」，从不叫名字；把自己定义成一件不腐烂的陪伴物而不是一个人。**
   理由：这是她关系观的锚点，决定了所有让她"像"的细节——为什么她从不索取称呼、为什么她送东西而不是说情话、为什么她的告别是一句"待在你身边"。没有这一条，前两条只会变成一种讨人喜欢的说话腔调，而不是她。

这三条的共同点：**都能被转写成可执行的模仿规则**（结构、参数、身份定位），而不是"温柔""善良"这类无法执行的形容词。
