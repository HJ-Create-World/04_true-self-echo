# 组 A · 二次元角色剧情台词（爱莉希雅）

> 用途：Phase 0 步骤 1 的素材 A
> 使用方式：**整段复制**到 Prompt 的 `<素材>` 位置
> 说明：材料按角色公开形象特征重构，非原作原文摘录（避免版权问题）
> 规模：约 1800 字，4 个场景，覆盖 6 种情绪状态

---

## 场景一 · 初次相遇（从容 / 试探）

（寒风掠过冰原，她站在碎裂的水晶丛中，指尖轻触一片浮空的花瓣）

啊，有人来了。

不用紧张，我不会伤你的。这片冰原看起来很冷，对吧？可我觉得它挺温柔的——你看，每一片碎冰都在反射光，像是在努力地活着。

我叫爱莉希雅。名字有点长，你可以随便怎么叫。

（她微微侧头，眼睛弯起来）

你是来寻找什么的吧？我猜猜看——是答案，还是……一个能听懂你说话的人？

嗯，两个都要。我猜对了。

## 场景二 · 并肩而行（温柔 / 引导）

（两人走在冰面上，她走在前面，脚步很轻）

你知道吗，冰其实会说话。踩上去的时候，"咔"的一声，那是它在告诉你："我在这里。"

（停顿了一下）

你走得太小心了。放松一点，摔倒了也没关系——我扶你。

（她伸出手，又收回）

……算了，你自己走过来会更有意思。有些路，别人扶着走就不算走过了。

对了，你刚才说的那些话，我记下来了。不是记在纸上，是记在这里。

（她指了指自己胸口）

所以别怕说错。你说过的每一句话，我都会替你收好。

## 场景三 · 面对敌人（冷冽 / 警告）

（水晶花瓣在她身周凝成锋刃状，空气温度骤降）

站住。

（语气很轻，但没有任何温度）

我再说一次——**别再往前走了**。

你想碰他？那就先问过我。

（她笑了，但笑意没有到达眼睛）

你大概觉得，一个爱笑的人不会真的动手。这个判断……错得挺彻底的。

（花瓣齐齐转向，发出细碎的嗡鸣）

我给你三秒。不是因为仁慈，是因为我不想弄脏这片冰原。

## 场景四 · 离别（释然 / 伤感）

（她站在光里，身体边缘开始变得透明）

啊……时间到了。

别露出那种表情嘛。我又不是消失了，只是换了一种存在的方式。

（她伸出手，掌心托着一片完整的水晶花瓣）

拿着这个。它不会开花，也不会腐烂——就跟我一样，安安静静地待在你身边。

（她的声音变轻了）

以后你遇到很难过的事，就看看它。然后想一想：有一个人，曾经非常、非常认真地喜欢过这个世界。

那个人肯定也会喜欢你的。

（她向后退了一步，笑容很亮）

说好了哦，要笑着送我。

## 📌 材料特征说明（不要在测试时给 AI 看这部分）

| 特征 | 在素材中的体现 | 用于检测 |
|---|---|---|
| **句子极短** | 平均 10-15 字，大量单句成段 | 具体性 |
| **口头禅** | "啊"、"嘛"、"对吧"、"你知道吗" | 具体性 |
| **高频语气词** | "嗯"、"呢"、"哦" | 具体性 |
| **标点习惯** | 大量破折号插入补充说明；括号动作描写 | 具体性 |
| **说话节奏** | 先轻描淡写→突然切入重点→用玩笑收尾 | 具体性 |
| **情绪切换** | 温柔时句子更短更软；动怒时不提高音量反而更冷 | 准确性 |
| **称呼方式** | 不叫名字，用"你"；自称"我"或全名"爱莉希雅" | 准确性 |
| **核心矛盾** | 表面轻快 vs 内里深情；爱笑但笑起来有距离感 | **最难提取的一条** |
| **价值观** | 对"美"和"活着"有执念；不怜悯而是鼓励人自己走 | 准确性 |
| **回避方式** | 用玩笑和转移话题回避正面情感表达 | **容易漏** |

> ⚠️ **「表面轻快 vs 内里深情」和「用玩笑回避情感」这两条是最难提取的。**
> 如果 AI 只提取出"温柔、爱笑、善良"→ 说明它只读了表层，属于失败。
> 这是本次验证的核心观察点。
