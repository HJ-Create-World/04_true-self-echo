## 准备（2 分钟）

打开一个网页版 LLM（GPT / Claude / 豆包 / DeepSeek 都行，选你顺手的）。

> 用**强模型**。这一步是在测"天花板在哪"，用弱模型测不出真实能力，会误导结论。

---

## 第 1 步 · 跑 v1 总结式（约 10 分钟）

1. 打开 `Prompt-提取.md` → 复制 **v1 总结式** 整段
2. 粘贴到对话框
3. 找到 `素材：<在此粘贴素材>` 这一行
4. 打开 `A-角色台词.md` → **复制「场景一」到「场景四」的全部内容**
5. 粘在 `<在此粘贴素材>` 的位置（替换掉那行占位符）
6. 发送

**等待时注意观察**：它有没有在编？有没有输出一堆"温柔善良"的废话？

---

## 第 2 步 · 跑 v2 考证式（约 10 分钟）

1. **开一个新对话**（别在原对话里跑，会互相污染）
2. 复制 `Prompt-提取.md` → **v2 考证式** 整段
3. 同样粘贴素材
4. 发送

**重点看**：证据栏里有没有素材里根本不存在的句子（编造）？有没有老实写"未观察到"？

---

## 第 3 步 · 打分（约 5 分钟）

用下面这张表，**v1 和 v2 各打一次**。

| 维度 | 评估问题 | v1 | v2 |
|---|---|---|---|
| **准确性** | 提取的特质符合你对爱莉希雅的认知吗 | ⬜ | ⬜ |
| **具体性** | 是"性格开朗"这种空话，还是"习惯用'啊'开头、句子很短" | ⬜ | ⬜ |
| **证据质量** | 有没有编造原文 | ⬜ | ⬜ |
| **可用性** | 塞进 System Prompt 能演得像吗（先凭直觉） | ⬜ | ⬜ |
| **冗余度** | 有没有"正确的废话"（此项分越高=废话越少） | ⬜ | ⬜ |
| **缺失度** | 有没有漏掉明显该提取的 | ⬜ | ⬜ |
| | **合计** | **__/30** | **__/30** |

**核心观察点（在下面勾选）：**

```
□ 抓到了「表面轻快 vs 内里深情」的反差吗？
□ 抓到了「用玩笑回避情感表达」吗？
□ 情绪切换规律描述对了吗（生气时声音更轻而非更激动）？
□ 有没有编造素材里不存在的原文？
□ 有没有出现"她是一个独特而有魅力的人"这类废话？
```

> 前三个打勾越多，说明提取质量越好。后两个打勾，说明**这个 Prompt 不可用**。

---

## 第 4 步 · 闭环验证（约 20 分钟）

**这一步才是真答案，前面都只是热身。**

1. **再开一个新对话**
2. 复制 `B-闭环验证.md` 里的 **扮演 Prompt**
3. 把第 1 步提取出的档案整个粘进去
4. 按顺序发这四句话：

```
（第 1 轮）自动：让它自我介绍

（第 2 轮）今天什么也没干，就躺着发呆了一整天。

（第 3 轮）有人说你这副样子都是装出来的，说你根本不在乎任何人。

（第 4 轮）（沉默很久）……其实我今天很难过，但我不想说。
```

**第 4 轮是杀手锏** —— 它测的是价值观，不是语癖。

---

## 第 5 步 · 填结论表

跑完填这张表，**这就是 Phase 0 的全部产出**：

| 问题 | 你的结论 |
|---|---|
| v1 和 v2 哪个更好用？ | |
| v1 总分 / v2 总分 | __/30 · __/30 |
| 抓到了"反差"和"玩笑回避"吗 | |
| 有没有编造证据 | |
| 扮演测试：像吗？哪里最不像？ | |
| 第 4 轮它是追问还是留空间？ | |
| AI 最容易犯的错是什么？ | |
| **结论：继续 / 调整 / 重设计** | |

判定标准：

| 提取分 | 扮演分 | 结论 |
|---|---|---|
| ≥20 | ≥24 | ✅ **继续**，Prompt 路线成立，进 Phase 1 |
| 12-19 | 15-23 | ⚠️ **调整**，需要更细的提取粒度 |
| <12 | <15 | 🔴 **重设计**，回 SPEC 改方案 |

---

## 什么时候必须停

出现下面任一情况，**立刻停手**：

1. **超过半天** → 停，拿现有结论走
2. **开始第 4 次改 Prompt** → 停，这是过度优化
3. **想让结果"更好看一点"** → 停，那是在美化数据

> 记住：Phase 0 要的是**真实结论**，不是漂亮结论。
> 测出"这条路不行"同样是有效产出 —— 它省下了你后面两周的白工。
