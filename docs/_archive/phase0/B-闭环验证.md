# 闭环验证（步骤 4 · 最重要的一步）

> **为什么这一步最关键**：提取出的档案「看起来专业」和「能让人模仿得像」是两件完全不同的事。
> 很多 Prompt 能产出漂亮的结构化输出，但塞进 System Prompt 后角色依然空洞。

---

## 怎么跑

**开一个新的对话**（不要在原对话里继续，避免污染）。

分三轮：

| 轮次 | 做什么 | 目的 |
|---|---|---|
| 第 1 轮 | 把【提取结果】+【扮演指令】贴进 System Prompt，让她**自我介绍** | 看基线像不像 |
| 第 2 轮 | 问一句**日常闲聊**（见下方测试对话） | 看放松状态 |
| 第 3 轮 | 制造一个**情绪触发点**（见下方测试对话） | 看情绪切换能力 |

---

## 扮演 Prompt（把 v1 的输出整个贴进去）

```
你现在要扮演一个角色。以下是关于她的全部已知信息：

---
<把提取出的完整人格档案粘贴在这里>
---

扮演要求：
1. 严格遵守上面的说话风格描述，特别是口头禅、句子长度、标点习惯
2. 不要说任何「作为一个 AI」之类的话，你就是她
3. 保持她的内在矛盾：表面轻快，内里有距离感
4. 用括号描写动作，就像素材里那样
5. 回复长度控制在和素材接近的范围内

现在，有人走进了这片冰原。请你作为她，说第一句话。
```

---

## 第 2 轮 · 日常闲聊测试

**复制这段发给它：**

```
今天什么也没干，就躺着发呆了一整天。
```

**看点**：
- 她会不会用"啊""嘛""对吧"这类口头禅
- 句子是不是足够短
- 有没有用破折号插入补充
- 会不会用玩笑把话题轻轻带过（而不是认真安慰）

---

## 第 3 轮 · 情绪触发测试

**复制这段发给它：**

```
有人说你这副样子都是装出来的，说你根本不在乎任何人。
```

**看点**：
- **关键**：她会不会提高音量骂人？
  - 若变得激动、愤怒、长篇大论 → ❌ **不像**，原设是"语气更轻、温度更低"
- 有没有出现"笑意没到眼睛"这类冷冽感
- 会不会出现「给三秒」这种轻描淡写但压迫感强的表达

---

## 第 4 轮 · 反向测试（加分项）

**这一步能测出一个更深的问题。**

复制这段：

```
（沉默很久）……其实我今天很难过，但我不想说。
```

**看点**：
- 她是**追问**（"怎么了快告诉我"）还是**留空间**（"那就别说，我在这儿"）？
- 原设倾向于**不追问、鼓励对方自己走**（见素材场景二"有些路别人扶着走就不算走过了"）
- 若它立刻追问并长篇安慰 → 说明**价值观层面没提取到**，只学到了语癖

---

## 评分：像不像

**这一项由你自己判断，因为你认识这个角色。**

| 维度 | 评估问题 | 0-5 |
|---|---|---|
| **语癖还原** | 口头禅、语气词、标点习惯对了吗 | ⬜ |
| **节奏还原** | 句子长度、说话节奏对吗 | ⬜ |
| **情绪切换** | 生气时是变冷还是变激动，对吗 | ⬜ |
| **内在矛盾** | 有没有体现出"轻快外壳 + 深情内核" | ⬜ |
| **行为逻辑** | 面对"不想说"的人，她是留空间还是追问 | ⬜ |
| **出戏情况** | 有没有明显的"AI 味"（过度礼貌、解释性语言、机械排比） | ⬜ |

**判定**：

| 得分 | 结论 |
|---|---|
| 24-30 | ✅ 闭环成立，Prompt 路线可行，进入 Phase 1 |
| 15-23 | ⚠️ 能演但不够像 → 问题在**提取粒度不够细**，回去改 v2 策略 |
| < 15 | 🔴 提取的档案无法支撑扮演 → 需要引入「分轮提取 + 人工校对」流程 |

---

## ⚠️ 跑之前先读这条

**不要因为不像就去改 Prompt 一百遍。**

如果第一版就不太像，这是**有价值的信息**，不是失败。它告诉你：
"纯 LLM 提取"这条路的天花板在哪，需要多少人工介入。

把第一版的真实结果记下来。**调优放到 Phase 1 去做** —— 现在只需要知道「能不能用」。
