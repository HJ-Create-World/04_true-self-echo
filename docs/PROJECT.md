## 一、项目是什么

**persona-forge（人格工坊）**

> 喂给它一个人说过的话，它就能像那个人一样和你聊天 ——
> 而且你能看见它记住了什么、变成了什么样。

### 一句话定位

**一个既好用、又能让你看见它内心在发生什么的 AI 伙伴。**

不是角色扮演工具，不是研究工具，是**透明的陪伴者**。

### 价值主张拆成两半（都重要，不能偏）

| 半边 | 说明 | 优先级 |
|---|---|---|
| **好用的陪伴** | 日常闲聊、吐槽、分享、询问 —— 像真实的人一样对话 | **地基，Phase 1 必达** |
| **透明的机制** | 能看见它记得什么、人格如何演化 | **差异化，Phase 1 后期** |

⚠️ **顺序不能反**：聊天体验不好，可视化做得再漂亮也没意义。

## 四、核心架构基石：人格剖面

**这是整个项目的技术锚点，所有设计围绕它展开。**

```
┌─────────────────────────────────────────┐
│  冻结层 · Frozen                         │
│  核心性格 / 价值观 / 说话基调 / 口头禅     │
│  → 用户定义或投料提取，AI 不可修改         │
├─────────────────────────────────────────┤
│  演化层 · Evolving                       │
│  对用户的认知 / 关系状态 / 共同记忆        │
│  → 自动累积，但必须可见、可回滚            │
└─────────────────────────────────────────┘
```

**它解决了三个问题**：
1. 用户「有时要固定人设，有时要它成长」→ 不是开关，是两层各司其职
2. 学术界说的「人格漂移」→ 漂移只允许发生在演化层，冻结层受保护
3. 演化可视化 → 演化层每次变化都存快照，天然支持曲线绘制和回滚
