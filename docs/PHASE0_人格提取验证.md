## 为什么先做这个

这是整个项目的**地基验证**。如果 AI 提取出的人格档案质量很差，那么：

- 投料模块做得再漂亮也没用
- 「像真实的人一样聊天」这个核心体验不成立
- 整个产品的价值主张崩塌

而验证成本极低 —— **不需要写代码，手工喂数据给 LLM 即可**。

## 验证方法

### 步骤 1：准备测试素材（三组，覆盖不同场景）

| 组 | 素材类型 | 要求 | 状态 |
|---|---|---|---|
| A | **二次元角色剧情台词** | 找一段有角色对话的剧情文本，500-2000 字 | ✅ **已就绪**（`phase0/A-角色台词.md`） |
| B | **真实聊天记录（熟人）** | 脱敏后的一段真实对话，50-100 条消息 | ⬜ 本轮跳过 |
| C | **人格设定文档**（对照组） | 一段现成的角色设定描述 | ⬜ 本轮跳过 |

> **本轮只跑 A。** 理由：A 是主要验证对象，且 HJ 本人能判断像不像 ——
> 这是唯一一组「有 ground truth 可对照」的素材。
> B 涉及隐私且需要脱敏，C 是锦上添花，都不该挡在第一次验证前面。
> 别为了「三组都跑一遍」把半天时间盒撑爆。

### 步骤 2：设计提取 Prompt

**待测试的 Prompt 结构（v1 草案）**：

```
你要从下面这段素材中，提取一个人的「人格档案」。

素材是这个人说过的话（以及对话上下文）。

请输出以下结构：

## 一、核心特质（冻结层）
- 性格关键词：3-5 个
- 价值观倾向：与什么的人/事自然亲近，排斥什么
- 情绪基调：整体偏什么情绪状态

## 二、说话风格（冻结层）
- 句子长度倾向：
- 标点习惯：
- 口头禅 / 高频词：（列出素材中出现 3 次以上的词）
- 语气特征：
- 表达习惯：（如：喜欢反问 / 直接下结论 / 先铺垫再表达）

## 三、称呼与关系（冻结层）
- 它怎么称呼对方：
- 它如何定义自己与对方的关系：

## 四、证据（重要）
每一条结论后面，请附上素材中的**原文片段**作为证据。
如果某一条你没有把握，请标注「证据不足」而不是猜测。

素材：
<在此粘贴>
```

**关键设计**：
- **要求附证据** —— 这样能一眼看出 AI 是"真的读懂了"还是"编了一套通顺的废话"
- **允许说"证据不足"** —— 防止 AI 硬凑

### 步骤 3：评估输出质量

用这个评分表打分（每项 0-5 分）：

| 维度 | 评估问题 | 分数 |
|---|---|---|
| **准确性** | 提取的特质，是否符合你对这个人的认知？ | ⬜ |
| **具体性** | 是"他性格开朗"这种空话，还是"他习惯用'哈哈'结尾，句子很短"这种具体特征？ | ⬜ |
| **证据质量** | 每条结论有没有真实原文支撑？有没有编造？ | ⬜ |
| **可用性** | 把这份档案直接塞进 System Prompt，AI 能模仿得像吗？ | ⬜ |
| **冗余度** | 有没有一堆"正确的废话"（比如"他是一个独特的人"）？ | ⬜ |
| **缺失度** | 有没有明显该提取但漏掉的？ | ⬜ |

**判定标准**：

| 总分 | 结论 |
|---|---|
| **20-30** | ✅ 方案成立，继续推进 |
| **12-19** | ⚠️ 需要调整提取策略（如改为「逐条提取口头禅」而非「总结人设」） |
| **< 12** | 🔴 方案需要重新设计 |

### 步骤 4：闭环验证（最重要的一步）

**把提取出的人格档案 + 一段新对话，喂给 LLM，让它"扮演这个人"回复。**

然后回答：

> **像吗？如果不像，差在哪？**

这一步才是真正的验证 —— **因为"提取出的档案好不好看"和"用它扮演像不像"是两件事。**
